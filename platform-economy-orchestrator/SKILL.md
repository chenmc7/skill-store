# platform-economy-orchestrator（平台经济讲义流水线编排）

薄编排层。本身不产出内容，只规定**调用顺序、档位、冲突裁决、学科语境与交付标准**。

## 一、固定调用顺序

```text
课件 (ppt/pptx/pdf)
   │
   ├─(1) courseware-notes     读课件、抽文本与图、套 assets/notes-template.tex 骨架
   │
   ├─(2) lecture-notes-zh     定章节结构与教学序列（8 段式 + 教学信号盒子）
   │
   ├─(3) rigorous-derivation  对每个公式/模型/命题做 L2 逐步推导
   │
   ├─(4) exam-problems        收录课件全部例题（蓝框）+ 验算，不出自造题
   │
   └─(5) courseware-notes     回填模板 → xelatex 编译 → 交付 .tex/.pdf/figures
```

**顺序要点**：
- 先 (2) 定结构，再 (3)(4) 填内容——否则推导与例题没有落点。
- 最后必须由 (1) 回填并编译，**不得**停在"给了 `.tex` 但没出 PDF"。

## 二、全局档位（默认值）

| 参数 | 默认 | 说明 |
|---|---|---|
| **推导档位** | **L2 逐步推导** | 每个实质操作单独成步并标依据；纯代数恒等变形可合并但须标注「代数化简」 |
| 讲义篇幅 | 中等详细 | 体系完整、推导不压、不写成论文 |
| 输出语言 | 中文（术语英文括注） | 公式与推导保持数学记号 |
| 例题范围 | 课件自带例题 | **全部收录**，不遗漏、不额外自造；课件未给例题的方法留白不讲题 |
| 图表 | 必要即收 | 结构性/曲线类图优先 **TikZ 重绘**；信息密集原页用截图 |

用户如说"尽量详细"，将推导档位提到 **L3**；说"先给个概要"则降到 **L1**。

## 三、冲突裁决（重要，覆盖子 skill 的默认规则）

| 冲突点 | 子 skill 默认 | 本项目裁决 |
|---|---|---|
| 推导深度 | `courseware-notes` 原规则倾向"不加长推导" | **推翻**。一律按 `rigorous-derivation` 的 L2 展开，`examplebox` 内必须给出完整步骤与依据 |
| 考点模块 | `courseware-notes` 原规则"默认不做名词表/易错点/考点" | **开启**。每章末必须有 `\subsection{本章小结}`（重点 + 必记公式 + 易错点） |
| 外部材料 | "只用课件" | **有限放宽**：必要的引理/文献/背景只能放在 `aiexplainbox`（浅蓝框）内，并注明"AI 补充"；**黑字正文仍严格限于课件来源** |
| 例题来源 | 无明确规则 | **收紧**：只收录课件自带的例题（蓝框 `examplebox`）；**禁止自造变式**，绿框 `variantbox` 不使用 |
| 例题位置 | 无明确规则 | **强制**紧贴对应方法所在小节，严禁堆到章末 |
| 命题证明 | 课件给"证明"时易被压成一句话 | **强制**：课件已给的证明必须按 L2 完整复现；课件只给结论的，证明放入 `examplebox` 并声明"补充推导" |

## 四、平台经济学语境

生成时按平台经济学语境处理。**以下清单不是穷举，但每一条都应在讲义中落到实处。**

### 4.1 核心概念块

- **平台 vs 管道**：平台 enable（促成）外部参与者互动；管道 control（控制）线性交易
- **网络效应**：同侧 / 组内（within-group，也称直接）；跨侧 / 跨组（cross-group，也称间接）
- **方向**：正向（用的人越多越好用）与负向（拥堵、广告骚扰）
- **两种"规模带来收益"**：网络效应在**需求侧**（提高用户支付意愿），规模经济在**供给侧**（降低单位成本）
- **价格结构非中性**：交易量取决于总价**在两侧之间的分配**，而不只是总价
- **外部性内部化**：私人参与激励 vs 社会边际收益的缺口，可用补贴弥合

### 4.2 经典模型与出处（可用于 `knowledgebox`）

| 模型 | 内容 |
|---|---|
| Rochet–Tirole (2003) | 双边市场定义；交易量 `Q = D_B(p_B)·D_S(p_S)`；价格结构非中性 |
| Belleflamme–Peitz (2021) | 平台定义（**促进互动 + 主动管理网络效应**，两要件缺一不可）；同质用户网络效用模型 `U(N)` |
| Belleflamme–Neysen (2023) | 控制权取舍与自营业务的平台化 |
| Metcalfe 定律 | 网络总价值近似与用户数平方成正比：`V(n) ∝ n²` |
| Armstrong | 竞争瓶颈（competitive bottleneck） |

### 4.3 建模与计算约定（**本学科最容易失分的地方**）

1. **先写可行域，再解一阶条件**。设好 `0 ≤ p_B ≤ p`、`N ∈ [0, N̄]` 之类的约束后再动手。
2. **一阶条件的解落在可行域外时，必须回到边界取最优**，并明确说明"这是边界解，不由内点一阶条件得到"。
3. **内点驻点 ≠ 全局最优**。二阶条件只判局部；全局最优必须比较所有候选点与端点（含 `N = 0`）。
4. **区分转移支付与资源成本**：接入费 `A`、价格 `p` 是用户与平台间的转移支付，在社会剩余中相互抵消；`c` 才是真实资源成本。
5. **显式声明归一化设定**：潜在交易量归一化、每人至多接入一次、用户把网络规模视为给定等。
6. 涉及补贴时，补贴额 = 边际外部收益，且要指出其**依赖当前规模** `N₀`。

### 4.4 术语（中文为主 + 英文括注）

平台（platform）、管道（pipeline）、网络效应（network effects）、同侧/组内（within-group）、跨侧/跨组（cross-group）、双边市场（two-sided market）、多边平台（multi-sided platform）、价格结构（price structure）、接入费/会员费（access fee / membership fee）、交易费（transaction fee）、外部性（externality）、社会剩余（social surplus）、内部化（internalize）、临界规模（critical mass）、免费增值（freemium）、吸引循环/吸引螺旋（attraction loop / spiral）。

### 4.5 高频易错点（优先写成 `warningbox`）

- 把一阶条件的解**直接当最优**，未检查可行域（如线性需求例解出 `p_B = −0.05` 已越界）
- 把"内点局部极大"误认为"全局最优"（内点驻点可能使总福利为负，低于零参与）
- 把接入费 `A` 当成社会成本（`A` 是转移支付，真正的成本是 `c`）
- 把"潜在配对数按平方增长"直接当成"网络价值必然按平方增长"（Metcalfe 依赖连接等值可加且无拥堵）
- 把"有网络效应"等同于"是平台"（还须存在**主动管理**网络效应的主体——世界语是反例）
- 把规模经济与网络效应混为一谈（一个在供给侧、一个在需求侧）
- 只看到网络效应"越好用"，忽略负向效应（拥堵、供给方被摊薄）

## 五、输出与交付

默认输出到**课件所在目录**下的 `讲义/<讲次名>/`：

```text
<课件目录>/讲义/<讲次名>/
├── <讲次名>_notes.tex
├── <讲次名>_notes.pdf
└── figures/
```

模板中署名统一为 `\NoteAuthor{讲义模板}`。

**边界（硬性）**：只允许在**输出目录内**写文件；**绝不改动源课件**及工作区其它文件。

## 六、完成前总检查

- [ ] 用了共享模板 `courseware-notes/assets/notes-template.tex`（`ctexart` + `xelatex`）
- [ ] `\section*{本节知识体系}` 存在且不进目录；`tocdepth=2`
- [ ] 黑字正文全部可追溯到课件；AI 内容全在浅蓝框
- [ ] 每个公式/模型/命题都有 **L2** 逐步推导（每步标依据，合并处标「代数化简」）
- [ ] 课件给出的证明已完整复现，未被压成"显然"
- [ ] 课件里全部可算例题已收录，全篇连续编号，一律蓝框 `examplebox`，均已验算（**无自造题**）
- [ ] **涉及最优化的题目均已检验可行域与端点**（边界解 vs 内点解）
- [ ] 每章末有 `\subsection{本章小结}`
- [ ] 图表：结构性/曲线图用 TikZ 重绘，其余用 `\notefigure`，题注有效，无 `[Image]` 占位符
- [ ] **已编译出 PDF**（不是只给 `.tex`）
- [ ] 编译成功后清理中间产物；失败则保留 `.log` 并说明原因

## 七、失败与降级

- `xelatex` 不可用 → 明确报告"无法出 PDF"，仍交 `.tex` + 图片，**不得谎称已编译**。
- 课件为扫描件/图片版 → 依赖 OCR 与目视检查；标签不清则不猜。
- 课件跨讲过多 → 逐讲产出，不要一次吞下整本。
- 课件前若干页若为课程行政信息（教师、考核、Quiz 日期） → **默认不收入讲义正文**，除非用户要求作前言收录。
