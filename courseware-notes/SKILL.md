# courseware-notes（课件 → 讲义骨架）

把一个**单一课件**（一讲 / 一章）转成高质量中文 LaTeX 讲义并编译出 PDF。

本 skill 负责流水线的**第一段与最后一段**：读课件、抽内容与图、套模板、编译交付。中间段（详细推导、例题精解、章节结构）分别由 `rigorous-derivation`、`exam-problems`、`lecture-notes-zh` 提供，由**学科对应的编排层**串联（`investment-lecture-orchestrator` / `platform-economy-orchestrator`，或用户直接按序调用）。

## 一、目标

讲义必须：

- 以**原始课件为主要来源**；
- 开头给出**本节知识体系**（不是照抄目录）；
- 逐知识点讲清课件内容；
- 在有助于理解处**裁切并插入关键图**；
- **课件来源内容用黑色正文**（原文、同义改写、忠实压缩、忠实重组）；
- **AI 补充的解释/例子/直觉/有限延伸一律放入浅蓝 `aiexplainbox`**；
- **例题、推导、证明、过程走查放入 `examplebox`，并按 L2 档位展开完整步骤**；
- 每章末给出**考点与易错小结**；
- 交付可编译 `.tex`、编译产物 `.pdf`、以及全部图片资源。

## 二、输入范围

支持：`.ppt` `.pptx` `.pdf`。

默认**不引入**课件之外的材料（教材、网页、往年题）。若需补引理，只能在 `aiexplainbox` 内、且要标注"AI 补充"。

本 skill **一次只处理一个课件/一章**，不做整本教材重写。

## 三、输出与交付

默认输出到**当前工作区相对路径**（不得使用绝对路径）：

```text
讲义/<章节名>/
├── <章节名>_notes.tex
├── <章节名>_notes.pdf
└── figures/
    ├── slide_08_示例.png
    └── ...
```

交付：`.tex` + `.pdf` + `figures/`。

## 四、必须使用的模板

起点一律为（相对本 skill 目录）：

```text
assets/notes-template.tex
```

复制模板并填写元信息宏：

```latex
\newcommand{\CourseName}{投资学}
\newcommand{\SlideDeckTitle}{第 X 章 ……}
\newcommand{\NoteTitle}{第 X 章 讲义}
\newcommand{\NoteSubtitle}{基于课件的图文讲义}
\newcommand{\NoteAuthor}{讲义模板}
\newcommand{\NoteDate}{\today}
```

**中文必须用 `ctexart` + XeLaTeX**，不要用 `inputenc`/`fontenc` 的 pdfLaTeX 方案。

模板不可用时，按 §十二 回退策略用最小 `ctexart` 骨架，但必须保留这些环境：`structurebox`、`aiexplainbox`、`examplebox`、`importantbox`、`knowledgebox`、`warningbox`、`notebox`、`\notefigure`、`lstlisting` 样式。

## 五、来源边界：黑字 vs 蓝框（本 skill 最重要的规则）

### 黑色正文 = 课件来源内容

可含：原文、同义改写、忠实压缩、忠实重组、相邻知识点的局部重排、课件明说或强隐含的解释。

必须可追溯到课件。**禁止**用黑字承载：课件之外的知识、自造例子、自造类比、背景扩展、猜测性解释、考点预测、来源存疑的说法。

**存疑即入蓝框。**

允许并鼓励：合并近似重复句、删掉铺垫与客套、把长描述压短、把密集句拆成编号列表。但不得替换原意、不得新增课件中不存在的结论或参数、不得把精确技术定义改写为含糊表述。

### 浅蓝说明框 `aiexplainbox` = AI 补充

用于：难点简释、公式缺符号说明时的补注、帮助理解的小例子、算法/几何/流程的局部直觉、直接支撑当前知识点的有限背景、易误解处的局部提醒。

尺度：**只需补到能理解当前知识点为止，不得喧宾夺主**。

```latex
\begin{aiexplainbox}[Explanation] ... \end{aiexplainbox}
\begin{aiexplainbox}[Tips]        ... \end{aiexplainbox}
\begin{aiexplainbox}[Note]        ... \end{aiexplainbox}
```

框标题用英文单词，**不用中文标题**；也**不要**仅靠改字色来表示 AI 内容。

### 课堂实录（仅双源模式启用）

当本轮存在课堂录音转写文本时（判定与流程见 `business-lecture-orchestrator` 的 L2 分支），老师课上讲过、而课件上没有的内容**同样放进 `aiexplainbox`**，靠**框标题**与 AI 补充区分：

```latex
\begin{aiexplainbox}[Lecture]
\textbf{课堂实录}\quad 这个式子考试一定考，你们要能自己推出来。\hfill\texttt{[00:42:15]}
\end{aiexplainbox}
```

- 框标题固定用 `[Lecture]`，与 AI 补充的 `[Explanation]` / `[Tips]` / `[Note]` 并列
- 框内首行用 `\textbf{课堂实录}` 标明来源；转写含时间戳时末尾加 `\hfill\texttt{[HH:MM:SS]}` 便于回听
- **严禁混用**：一句话要么是老师说的、要么是我们想的，必须一眼可辨
- 课堂实录总量**不超过正文的 1/3**，否则喧宾夺主
- 无录音时**不出现** `[Lecture]` 框

## 六、文档组织

1. 封面（模板提供）
2. 目录
3. 星号节 `\section*{本节知识体系}` + `structurebox`（**不进目录**）
4. 按知识点分节
5. 局部对比 / 公式解释 / 代码解释，紧贴相关知识点
6. **每章末 `\subsection{本章小结}`**：本讲重点 + 必记公式 + 易错点 + 可继续追问方向

目录深度：

```latex
\setcounter{tocdepth}{2}
```

标题层级默认映射：课件一级 → `\section`，二级 → `\subsection`，更细 → `\subsubsection` 或加粗行内标题。**不要**把课件的子节升格为 `\section`。允许的轻度重构：合并同义子节、拆分超载子节、为含混标题改名、丢弃无内容的空标题。

写作时**不要**出现"课件列举""PPT 中提到""幻灯片展示"这类转述腔——读者读到的应是关于学科本身的讲义，而非对别人幻灯片的描述。

## 七、图表处理

**图是本 skill 的核心**。许多课件的关键信息在图里。

**优先收录**：算法可视化、数学/几何图、UML、架构图、流程/管线图、前后对比图、曲线/图表、强于文字的表格关系图、离开图就讲不清的密集页。

**避免**：纯标题页、装饰图、重复图、低信息图标、只需局部却整页截图、裁了也看不清的图。

**裁图准确性是硬要求**：裁错（切掉标签、坐标轴、图例、关键标注）比不放更糟。落盘前必须目视核对裁切结果；**不得**只凭文本抽取推断裁切坐标。

图片理解必须来自**真实的视觉检查**（渲染后的页面图），不能只靠 OCR 或文件名。

**禁止**在正文留 `[Image]`、`[Figure]` 之类占位符。每张图都用：

```latex
\notefigure[0.72]{figures/slide_08_示例.png}{示例图：……}
```

宽度建议：`0.50–0.65` 小图/流程图；`0.68–0.78` 多数算法图/UML/数学图；`0.82–0.92` 密集多标签图。**不要**一律 `0.90+`。图片用 `[H]` 就近放置，题注说明"这张图支撑什么"，而非复述文件名。

**盒子内不放图。**

### 关键图优先用 TikZ 重绘（矢量，比截图清晰）

当图属于以下类型时，**重绘优于截图**：

- **结构示意图**：网络拓扑（星型/环形/全连接）、双边市场两侧关系、管道 vs 平台对比
- **函数曲线**：价值随规模增长、福利 `W(N)` 随 `N` 变化、需求/供给曲线、盈亏区间
- **简单几何、流程、时间轴**

```latex
\begin{figure}[H]
\centering
\begin{tikzpicture}[scale=1]
  % 坐标、节点、标注必须与讲义正文的记号一致
\end{tikzpicture}
\caption{题注：这张图支撑什么}
\end{figure}
```

模板已加载 `tikz` + `pgfplots`（`compat=1.18`）及库 `arrows.meta, positioning, calc, decorations.pathreplacing, shapes.geometric`。
绘图内的符号、数值、量纲**必须与同页正文自洽**。

**仍应截图的情况**：信息密集的原页（多栏表格+文字混排）、软件界面、真实照片、课件自带的数据图（重绘会失真）。
**判据**：重绘后是否**更清晰且无信息损失**——只要会丢信息，就用截图。

**先探测课件的图形是位图还是矢量**（决定整个插图策略）：
```bash
pdfimages -list "课件.pdf"    # 无输出 = 全篇无位图 = 图形都是矢量
```
若课件本身是矢量产出（LaTeX Beamer / 带 TikZ 的 Keynote 导出等），**截图反而是降质**（150dpi 位图清晰度低于原生矢量）——此时应把策略整体切到「**全部 TikZ 重绘、零截图**」，连 `figures/` 目录都不必创建。这类课件的图通常不多（实测某 87 页 Beamer 课件只有 5 处小示意图，其余全是文字+公式+表格）。

### 两条实战教训（务必照做）

1. **表格优先用 LaTeX 重排，不要截图**。`booktabs`（`\toprule/\midrule/\bottomrule`）+ `multirow` 重排的表格比截图清晰得多，且正文可引用。只有"图里套表、重排会丢结构"时才截图。
2. **由谁来目视核对**：若本任务委托了子代理，而**子代理报告"无法查看图片（内容被过滤）"**，则**必须由主代理亲自渲染页面并逐张目视复核**，不得仅凭"编译 0 警告 + 文本层比对"就认定图表正确。
   - 渲染：`pdftoppm -r 100 -png <notes>.pdf <tmp>/pg` → 用图片读取工具逐张看
   - 核对清单：坐标轴/图例/标签未被切掉；图内数值与正文一致；截图不是空白页或纯标题页
3. **TikZ 图必须目视核对标签重叠——它不报错，只画成叠字**。`Missing character` 与 `!` 错误都查不出节点重叠，**只有看图能发现**。已实测的三类高发重叠（固收 L1 一次撞上 3 处）：
   | 症状 | 成因 | 修法 |
   |---|---|---|
   | 图底部**说明行**与落在同一水平线的**末端标签**叠字 | 说明行沿 x 方向很长，右端伸到了末端主箭头标签的正下方 | 把说明行的 y 再往下移 1 个单位（如 `-1.75` → `-2.75`），或把说明行缩短 |
   | 相邻时间点的**两个文字标签**粘成一串（如"发行日起息日 / IssueDated"） | 两个 `\node` 的 x 只差 <1 个单位，而每个标签宽度 ≈2 个单位 | 合并为一个标签（`发行日（Issue）\ / \ 起息日（Dated）`），或把两者 x 拉开 ≥2 个单位 |
   | **坐标轴刻度数字被箭头盖住**（数字消失或半截） | 刻度数字与箭头落在同一 x 上 | 把与该箭头同 x 的刻度数字挪到轴的另一侧；或把该组箭头整体偏移 0.25 个单位使其避开整数刻度 |
   | **函数曲线穿过文字标签**（标签被切字） | 标签放在曲线围出的填充区里，或紧贴曲线的水平段 | **按曲线解析式把标签位置算一遍**：比较标签的 x 区间内曲线的 y 极值与标签的 y 区间；或把标签移到曲线明显不经过的空区 |

   **交付前固定动作**：把所有含 `tikzpicture` 的页面单独渲染成图，逐张确认——(a) 无叠字，(b) 每个标签都能读全，(c) 每个刻度数字都可见，(d) 箭头不穿过任何文字，(e) **曲线不穿过任何文字标签**。

### 四个高频技术坑（2026-09-30 新增，投资学 6\&7-4 实测）

1. **TikZ 样式名不能撞保留键**。`out` 是 `to[out=.., in=..]` 的键——写成 `out/.style={...}` 会报 `The key '/tikz/out' requires a value`，并且会**级联**污染同一文件后面所有 pgfplots 轴选项（典型症状：`label style={font=\small}` 被当成 `\label` 命令执行，报 `Undefined control sequence \__hook label`）。改个名（如 `fin`）即可，**不要**去改那些看似无辜的轴选项。
   **已知会撞的键：`out`、`step`**（2026-10-02 投资学 6\&7-3 实测：`step/.style` 报 `/tikz/step requires a value`，并连带引发 34 处 `Not allowed in LR mode` / `Missing }` / `Giving up on this path` 等级联错误）。命名 TikZ 样式前，先把候选名与 `to`/`step`/`node`/`path` 这类保留键比一遍。

2. **判断「真编译错误」要认行首的 `! `（叹号 + 空格）**。`grep -c '^!'` 会假报错：pgfplots 的 Overfull 日志在转储公式时会把希腊字母 ω 渲染成 `!`，令行首出现 `!`。统一用
   ```bash
   echo "真错误=$(grep -c '^! ' x.log)"; echo "缺字=$(grep -c 'Missing character' x.log)"
   ```

3. **`\newpage` 会留下几乎全空的页**。tcolorbox 跨页后紧跟 `\newpage`，会把盒子的一行尾巴单独留在一页、其余全空。**页数超标时先删章前的 `\newpage`**（只保留导言与首个技术章前的），比删内容省事、也更不影响可读性。实测：投资学 6\&7-4 靠删 6 处 `\newpage` 从 32 页压到 28 页。

4. **均值--方差类的「子弹形可行集 + 外部切线」图，分离度必须在画之前算**。若前沿的渐近斜率 $k$ 接近切线（CAL）斜率 $m$，两条线会几乎重合、图完全不可读（实测两版都栽在这里）。做法是先按切线条件定参数：
   $$s=\frac{k\sigma_0^2}{E_0-r_f},\quad \sigma^*=\sqrt{s^2+\sigma_0^2},\quad E^*=E_0+ks,\quad m=\frac{E^*-r_f}{\sigma^*},$$
   再让 $m-k$ 足够大（分离度 $\approx (m-k)\sigma$）。**被标注的资产点要放在纵向间隙最大的 $\sigma$ 处**，否则读者看不出「它在不在这条线上」。

### 五个补充技术坑（2026-10-02 归位自项目记忆）

5. **阶梯图 / 曲线族图的文字标签：改用区间色带，别逐点试算**。逐个算坐标找空位非常不可靠（国际贸易 L3 实测两处重做）。有效解法是在 `\addplot` **之前**用 `\fill[blue!7] (axis cs:0,0) rectangle (axis cs:3.6,4.0);` 画出区间底色，区域文字放在**色带顶部**（高于该区间内曲线的最高点），公式与轴值标签放在曲线明显不经过的角落。一次到位，比逐点试算漂亮。

6. **pgfplots 三个必记的坑**：
   - `symbolic x coords` 与数值 `xmin/xmax` **冲突**，报 `Sorry, the input coordinate '0.3' has not been defined` → symbolic 轴只用 `enlarge x limits`
   - 年份刻度自动加千分位（1900 渲染成 `1,900`）→ axis 选项加 `xticklabel style={/pgf/number format/1000 sep=}`
   - 百分数刻度用 `yticklabel={\pgfmathprintnumber{\tick}\%}`

7. **`\caption*` 在本环境不可用**：**不报错**，但渲染成「图 N: \*」，还白白消耗一个图号。跨页表格与图表说明改用 `\begin{center}...\end{center}` + `{\small 表：……}`；表格过宽时用 `{\small ... }` 包住 tabular 消 Overfull。

8. **多系列图的图例必须放在坐标区外**（世界发展 Lec1 实测）：六条线的折线图把图例放在区内右下角（`at={(0.98,0.02)}, anchor=south east`），会**盖住右侧三条款**——`fill=white` 是不透明的，被盖住的曲线直接消失。解法：`legend style={at={(0.5,1.03)}, anchor=south, legend columns=3}` 移到图上方；三条线以下、图例区确为空白时才可留在区内。**该缺陷编译 0 错误，只能靠 250dpi 渲染放大目视发现。**

9. **`\toprule` 不能用在 `array` 里**：`\[\begin{array}{ll}\toprule ... \end{array}\]` 报错（booktabs 的规则线只面向 `tabular`）。表内规则线一律用 `center` + `tabular` 包起来，不要塞进数学环境。

10. **小数刻度轴：pgfplots 会混排科学计数法与小数值**（2026-10-02 投资学 6\&7-3 实测）。`xmin=0, xmax=0.24` 这类轴，自动刻度给出 `2·10⁻² 4·10⁻² 6·10⁻² 8·10⁻² 0.12 0.14 …`——两种格式混在一起、标签互相挤压。修法是**显式指定刻度 + 强制定点格式**：
    ```latex
    xtick={0,0.05,0.10,0.15,0.20},
    scaled x ticks=false,
    xticklabel style={/pgf/number format/fixed, /pgf/number format/fixed zerofill,
                      /pgf/number format/precision=2, font=\footnotesize},
    ```
    **该缺陷编译 0 错误 0 警告，只能靠渲染目视发现**——凡坐标轴取值范围小于 1 的图，渲染后必须逐个确认刻度标签。

11. **TikZ 图的整体宽度要比 `\textwidth` 保守**（2026-10-02 实测）。`text width=12.2cm` 的节点在 A4 + `margin=2.2cm`（可用宽 16.6cm）下仍溢出了右边界，原因是 `right=... of` 定位后 bounding box 偏右。**宁可纵向堆叠也不要横向铺满**：三个 `text width=11cm` 的节点上下排列，比两个 5.2cm 并排 + 一个 12.2cm 跨列更安全，也更易读。

12. **TikZ 标签必须落在「曲线明显不经过的空区」——先算后放，不要目测**（2026-10-02 国际贸易第 4 讲实测，一页三处翻车）。三种典型翻车与修法：
    - **交点标注压在两条曲线上**：把 `(x^*, y^*)` 的说明文字放在交点旁，文字正好横跨两条曲线 → 改放到坐标区的空白角落（如右下角 `(axis cs:1.12,0.16)` + `anchor=south west`）；
    - **曲线名标签压在曲线上**：`本国 MPL` 放在 `(axis cs:9,4.55)`，而该 x 区间的曲线正好在 4.0–5.3 之间穿过 → **按解析式把标签 x 区间内曲线的 y 极值算一遍**，选一个与该区间无交叠的 y；
    - **标签落在坐标区外被静默裁掉**：`anchor=west` 放在 `x=101`（而 `xmax=100`）→ 文字直接消失，**编译 0 错误 0 警告**。凡标签坐标 > 轴范围上限的，一律挪回区内。
    **判据**：标签的 (x 区间 × y 区间) 与曲线的 (x 区间 × y 区间) **必须有非空补集**；只靠「看起来差不多」一定会翻车。
13. **世界地图与「把中国台湾、中国香港单列为国家」的国别表格，一律不截图**（合规红线，2026-10-02 实测触发两次）。修法：
    - **地图**（移民流量图、各国最大贸易伙伴图、半导体全球产业链图等）：讲义**不重制地图**，改用「文字描述 ＋ LaTeX 数据表」，并加一条 `notebox` 指向课件原页（「讲义不重制地图，请对照课件原页查看分区」）；
    - **国别表格**：用 `booktabs` **重排**（本来就该重排，比截图清晰），并把中国台湾、中国香港按**单独关税区**口径写作「中国台湾地区」「中国香港地区」，附一句注说明原始来源的列示方式不改变其法律地位。
    - **务必注意**：这类课件常把表格/图做成**矢量轮廓文字**，`pdftotext` 与 `pypdfium2` **抽不出文字**，因此「按文本层搜敏感词」**查不出来**——唯一的把关手段是**逐张目视**（本次正是靠肉眼看截图才发现）。

### 三个交付前必查项

- **`Missing character` 计数必须为 0**——中文/符号缺字**不报错但会渲染成空白**。已知 `▢`(U+25A2)、`①②`(U+2460/2461) 在 lmroman 下缺字，改用 `$\square$` 与全角括号。
- **grep 一次 `\*\*`**——写作时手滑把 markdown 粗体写进 LaTeX，**编译不报错**但会渲染出字面星号（经济学研究方法 Lec1 实测抓到 6 处）。
- **`structurebox` 三段式之间的换行加距必须写 `\\[1.5mm]`**。误写成 `\[1.5mm]` 会被当成**行间公式开始**，报 `Display math should end with $$`（错误行却指向后面那行 `$...$`，极易误判）。批量修正**不能用简单 replace**——`\\[1.5mm]` 里含 `\[1.5mm]` 子串，会把已正确的也改坏。用负向断言：
  ```python
  re.sub(r'(?<!\\\\)\\\[1\.5mm\]', lambda m: '\\\\[1.5mm]', s)
  ```

## 八、处理流程

1. 检查文件名与元信息
2. `ppt/pptx` → 先转 PDF
3. 从 PDF 逐页抽文本
4. 每页渲染为高分辨率 PNG
5. 目视检查页面，定位关键视觉区域
6. 裁切关键图，存入 `figures/`
7. 按模板撰写 LaTeX 讲义
8. XeLaTeX 编译
9. 交付 `.tex` / `.pdf` / `figures/`

推荐工具（**任一可用即可，不要因单一库缺失而卡住**）：

| 环节 | 首选 | 备用链 |
|---|---|---|
| 页数/元信息 | `pdfinfo` | PyMuPDF |
| ppt/pptx → PDF | `soffice --headless --convert-to pdf` | — |
| 页面渲染为 PNG | PyMuPDF(`fitz`) | `pypdfium2` → `pdftoppm`（poppler，TeX Live 自带） |
| 抽文本 | PyMuPDF / `pdftotext` | `pypdf` |
| 裁图 | Pillow | PyMuPDF 的 clip |

> 实测：本机 **未装 PyMuPDF**，用 `pypdfium2 + pillow + pypdf + pdftoppm` 同样跑通，勿因此中止。

文本层质量差时，**以渲染页图为准**，不要假设抽取文本已包含全部重点。

## 九、代码处理

面向算法/编程类课件（数据结构、数据库、编译原理、操作系统、计算机网络等）时收录关键代码：核心循环/递归/状态更新、规范数据结构骨架、代表性 SQL/查询计划、最小完整示例。**省略**文件头、include、main 包装、重复近似的片段、与教学无关的框架脚手架。

```latex
\begin{lstlisting}[language=Python,caption={快速排序的核心划分过程}]
...
\end{lstlisting}
```

非真实语言的伪码用 `language={}`。只需提一句时用 `\lstinline|...|`。每个非平凡代码块加**必要而简短**的行内注释，解释**为什么**（不变量、边界条件、该操作的角色），不是复述语法。原注释好则保留。原代码可能有误时，在 `aiexplainbox` 里说明，不要静默改意。

## 十、例题、推导与证明

凡需展示推理的课程（投资学、金融工程、计量、随机过程、最优化等），课件给出的题目**必须走通思路**，光给答案不算。

- 每个例题/推导/证明放入 `examplebox`，按 **L2 档位**展开（详见 `rigorous-derivation`）：
  - 每个实质性操作单独成步并标依据；
  - 纯代数恒等变形可合并，但须标注「代数化简」。
- 若课件只给题不给解，可补推导，但必须在框首声明：

```latex
\begin{examplebox}[Derivation]
\textbf{说明.} 本题解答为补充推导，原课件仅给出题目条件。
...
\end{examplebox}
```

- 例题的**收录规则**见 `exam-problems`（收录课件里**全部**可算例题，不遗漏、**不自造**；全部用蓝框 `examplebox`）。
- **证明与长推导同样放入 `examplebox`**，标题分别用 `[Proof]` 与 `[Derivation]`（与例题共用一种视觉样式，靠标题区分）。这样与 `importantbox`（结论）、`knowledgebox`（背景）、`warningbox`（易错）互不混淆。
- 复现课件已有的证明时，**不得压成"显然""可得"**；每一实质步骤仍须标依据。

## 十一、写作风格与公式

- 默认**中文**；关键术语保留英文括注（如 有效前沿（efficient frontier））。
- 用清晰的分节；凡是可枚举内容（类型、性质、步骤、条件、成分、优缺点）一律用编号/项目列表，不写成大段文字。
- 避免长段不换行；单个视觉块通常不超过三到四行。
- 避免"本文主要介绍了""综上所述"等填充；避免"不是……而是……"滥用。
- `\textbf{}` 只给关键术语/定义/一句中最重要之处，每段最多 1–2 处，不整句加粗。
- 公式：准确保留；若课件未给符号说明，就近加 `aiexplainbox`。
- 展示数学用 `\[ ... \]`，行内用 `\( ... \)`；**避免**单美元行内数学。
- 不编造事实、参数、结论；不插引用占位符；不加外链（除非用户要求）。

## 十二、长课件策略

课件页数多或图密集时，**不要单遍通吃**：内部分成连贯的页段，逐段抽文本/图/知识点，再整合为一份统一讲义，去除重复解释，保持整体连贯，而非拼贴分块摘要。除非课件损坏/加密/超限，不要要求用户手动切块。

## 十三、回退策略

- **转换失败**：报告问题；有 PDF 版就用 PDF；不得凭文件名臆造内容。
- **文本抽取差**：以渲染页图与目视检查为准，保守处理不确定内容；标签看不清不猜。
- **模板缺失**：用最小 `ctexart` 骨架，保留必需环境，样式从简。
- **XeLaTeX 编译失败**：保留 `.log` 排查；补包、修图片路径/Unicode/语法；编够次数以解析目录与引用。仍失败则交 `.tex` + 图片 + 简明错误说明。
- **课件过长过密**：处理最连贯的完整页段；明确说明完成与未完成部分。**宁可局部忠实，也不要整体压缩后臆造。**
