# 商科讲义生成总编排（两层结构 · 2026-10-10 重整）

薄编排层。本身不产出内容，只负责**判定层级、规定调用顺序、裁决规则冲突、把关交付标准**。

一律按**商科**语境处理，**不询问课程名称**——按课件实际内容自行判定领域。

## 〇、怎么用这份 skill

**一句话定位**：本 skill 不产出内容，只负责**判定、排序、裁决、把关**——真正干活的是四个下游内容 skill：
`courseware-notes`（读课件／套模板／编译）、`lecture-notes-zh`（定教学结构）、
`rigorous-derivation`（逐步推导）、`exam-problems`（例题精解）。

**出问题时先分清责任**：内容问题看下游 skill，流程问题看本 skill。

### 我要做 X → 看第 N 节

| 你要做的事 | 看哪一节 |
|---|---|
| 第一次把一份课件做成讲义（无录音） | 一 → 二·A1 |
| 课件之外还拿到了课堂录音 | 一 → 二·A2 |
| 已有讲义，后来又拿到局部录音 | 三·B1 |
| 已有讲义要按新体例重做（批改作业） | 三·B2 + 五 |
| 一次给同门课多个课件、要求合成一份 | 四·V1 |
| 一次讲次只录到一半 | 四·V2b |
| 老师的课到底怎么用（长期约定） | 五 |
| 交付前该查什么 | 六 |
| 每次做完必做的一件事 | 七 |
| 踩过的技术坑 | 八 |

**调用方式**：用户说「把这份课件做成讲义」「整理成讲义」即触发；也可显式点名本 skill。

## 一、通用开局：三步定位

### 第 1 步｜确定课程目录与课件

以用户给出的课件路径为准，其所在目录即本轮课程目录。

**若用户一次给出同一门课的多个课件并要求「做成同一份」**——先跳到 **四·V1｜多课件合订模式**，按那里的五项对齐清单与三件套手法开工，不要逐个课件各做一份。

### 第 2 步｜判定层级 L1 / L2（按顺序检查，命中即停）

```text
① 用户明说
   "有录音 / 有转写 / 有课堂记录 / 老师课上讲了"  → L2
   "只有课件 / 没录音 / 就这个 PDF"              → L1

② 同目录同名匹配（以课件主文件名为基准）
   Chapter11.pdf  →  查找
     Chapter11*.{txt,md,srt,vtt,json}
     *Chapter11*{转写,transcript,录音,课堂}*
     同目录下 *{转写,transcript,录音,课堂}*.{txt,md,srt,vtt,json}

③ 目录约定
   <课程目录>/录音/、<课程目录>/转写/、<课程目录>/transcript/ 下的文本文件

④ 内容特征（对候选文件抽样前 50 行）
   含时间码：[00:12:34] / 00:12:34.000 / HH:MM:SS
   含口语标记："嗯""这个""那么""我们说""大家看"
```

**判定结果**

| 情况 | 动作 |
|---|---|
| 命中任一 | 走 **L2 双源**，在首条进度消息中说明命中的转写文件 |
| 全未命中 | 走 **L1 单源**，正常开工 |
| 模糊或冲突 | **先按 L1 开工**，在首条进度消息中说明「未找到转写文本，按单源处理；如有请放到 `<课程目录>/` 下并告诉我」 |

**铁律**：不得因层级判定拖延开工；**不得因无录音而降低讲义质量**——L1 是完整流程，不是简版。

### 第 3 步｜确定受众档位（解释密度）

用户可能指定自身基础水平，据此调整讲义的解释密度：

| 档位 | 触发条件 | 做法 |
|---|---|---|
| **标准**（默认） | 用户未说明 | 正常讲解；术语中文为主 + 英文括注；推导按 L2 |
| **零基础友好** | 用户说「基础薄弱」「刚接触这门课」「讲详细些、要能看懂」「看不懂推导」 | ① 每个术语首次出现给一句大白话解释；② 用 `knowledgebox` 就近补前置知识（期望、条件期望、方差与协方差、OLS 残差、$R^2$、虚拟变量、标准误与 t 检验等）；③ 每个公式先讲「为什么需要它」再给形式；④ 反直觉结论用 `warningbox` 明确提醒；⑤ 直觉与类比优先于形式化。补到能读懂当前推导为止，**不展开成教科书** |

**默认标准档**；判不出档位时按标准档开工，不额外询问。

## 二、主线 A · 从零生成讲义

> 无录音走 A1，有录音走 A2。两者只在「前置步骤」与「缝合」两处不同。

### 二·A1｜L1 单源模式（只有课件）

```text
课件 (ppt/pptx/pdf)
   │
   ├─(1) courseware-notes     读课件、抽取文本与图、套 assets/notes-template.tex
   ├─(2) lecture-notes-zh     定章节结构与教学序列（8 段式）
   ├─(3) rigorous-derivation  每个公式/模型做 L2 逐步推导
   ├─(4) exam-problems        收录课件全部例题（蓝框）+ 验算，不出自造题
   └─(5) courseware-notes     回填模板 → xelatex 编译 → 交付
```

- 先 (2) 定结构，再 (3)(4) 填内容——否则推导与例题没有落点
- 最后必须由 (1) 回填并编译，**不得停在「给了 .tex 但没出 PDF」**

**L1 不产出「课堂实录」层。**

### 二·A2｜L2 双源模式（课件 + 录音转写）

在 L1 的 (1) 之前插入三步前置工作，在 (4) 之后、编译之前插入「缝合」步：

```text
课件 (ppt/pptx/pdf)                    录音转写 (txt/md/srt/vtt/json)
   │                                          │
   │                            (0a) 预处理：分段、纠错字、统一时间戳
   │                            (0b) 锚点对齐：转写语义块 → 讲义小节
   │                            (0c) 增量筛选：四分类，丢弃约七成
   │                                          │
   ├─(1) courseware-notes     读课件 + 消费对齐结果
   ├─(2) lecture-notes-zh     定章节结构
   ├─(3) rigorous-derivation  L2 逐步推导
   ├─(4) exam-problems        例题精解（课件原题，不出自造题）
   ├─(5) 缝合课堂实录          逐点插入 aiexplainbox（标签「课堂实录」）
   └─(6) courseware-notes     编译 → 交付
```

### (0a) 转写预处理

> **先用工具，再读规则**（2026-10-10 起）。本节的每一条都有对应命令：
>
> ```bash
> python _tools/transcript_kit.py probe   <转写文件>   # ① 结构探明（排布/说话人分布/单调性/时长）
> python _tools/transcript_kit.py detect  <转写文件>   # ② 幻觉与异常段
> python _tools/transcript_kit.py glossary <转写文件> --course investment   # ③ 术语订正
> python _tools/transcript_kit.py merge   <转写文件>   # ④ 粒度合并（逐小句→段落级）
> python _tools/transcript_kit.py quality <转写文件>   # ⑤ 质量报告（可用率/建议层级）
> python _tools/transcript_kit.py compare <A> <B>      # ⑥ 同课判定
> python _tools/transcript_kit.py split   <文件> --cut HH:MM:SS --left a.md --right b.md   # ⑦ 跨讲切分
> ```
> 工具的能力边界：检测基于**词表与形态规则**，只能抓**词汇层面**的幻觉；
> **语义层面的讹写**（如英文句子被听错成另一个句子）抓不到，必须人工抽查一段正文。

- **先探明文件结构，再写解析脚本**——不同 ASR 工具导出的排布不一样，猜错会得到全盘错误的时间戳：
  | 结构 | 特征 | 处理 |
  |---|---|---|
  | 一段一带时间码 | 每段形如 `说话人N HH:MM:SS 正文…` | 直接解析 |
  | **时间码段 + 正文段交替**（实测于讯飞系导出） | 相邻段落里偶数段**只有** `说话人N + HH:MM:SS`、奇数段才是正文；段落总数 ≈ 内容段数 × 2 | 时间码段是**下一个**正文段的标记，须**配对还原**。若不察，会把一半段落判成"无文字"并给出错位时间戳 |
  | 纯正文无时间码 | 无 `HH:MM:SS` | 按自然段与话题转移切分 |
  | **「发言人1　01:06」式**（全角空格） | 世界发展两份实测 | 与「说话人」同规则处理（工具已支持 `说话人\|发言人\|Speaker`） |
  | 纯正文无时间码 | 无 `HH:MM:SS` | 按自然段与话题转移切分 |
  - **判据**：先统计「只含说话人+时间码的段落占比」。若接近 50%，就是交替结构
  - 说话人与时间码常被粘连（`说话人101:39:01` = 说话人 1 + `01:39:01`；`说话人138:27` = 说话人 1 + `38:27`；`说话人201:07:44` = 说话人 2 + `01:07:44`）。**说话人号只占 1 位数字**，**先按"说话人 + 一位数字 + 时间码"拆**，再用"时间码是否单调递增"验证拆法正确
  - **反面教训**：用贪婪的 `(\d+)` 匹配会把说话人号与分钟首位粘连——`说话人210:36` 被读成"说话人 21 + `0:36`"（实为 10:36），于是**时间戳整体错乱且表面上仍像正常时间**。正确正则 `^说话人\s*(\d)(\d{1,2}:\d{2}(?::\d{2})?)$`。**单调性是唯一可靠的验伪手段**
- 带时间戳 → 保留为 `[HH:MM:SS]`（引用时**必须用真实段号/时间码**，便于回溯原始文件）
- **剔除课间闲聊**：休息时段常把学生私下对话也转进去（含私人话题）。定位法——搜「休息 X 分钟 / have a rest」找起点，搜恢复上课的标志句找终点；剔掉的区间**既不写入讲义，也不在讲义里提及**
- **修 ASR 错字**：用课件术语表逐项对照。**人名、模型名、公式名、数字最易错**
- **老师口述数字与课件冲突时以课件为准**，并在 `warningbox` 里写明"老师口述为 X、课件为 Y"
- **先判「这批转写与手上已有的那批是不是同一节课」，再决定要不要重做讲义**（2026-10-07 国际贸易实测，不判会白做一遍）：
  1. 归一化：去掉时间码行、说话人标签、全部非中文/数字/字母字符，拼成一条长串；
  2. 取 100–150 字的探针，在对方文本上**滑窗**（步长 50）用 `difflib.SequenceMatcher` 找最佳对齐位置，得到对齐偏移；
  3. 在对齐区取 2–3 段各约 1500 字算**逐字相似度**。**实测判据：≥ 0.80 ＝ 同一节课的不同转写版本；0.08–0.12 ＝ 完全不同的课**（本例旧件对 `9月24日` 为 0.85 / 0.83，对 `9月22日` 为 0.09）；
  4. **不要用短片段集合比对来判定「同课」**——同一段音频的两个 ASR 版本措辞有细微差别（「物品」↔「股」、「布匹」↔「布局」），18 字片段集合的重合率只有 10–13%，会把同课误判成异课。片段集合只适合判**异课**：重合率 0% 才是强证据。
  - 判为同课后还要判**哪一份更全**：对齐偏移 > 0 且新件在偏移之前仍有内容 → 新件是**全本**、旧件是被截掉开头的版本。此时旧件的实录时间码需按偏移量重新换算，且**实录框的「第 N 次课」批次要按真实课序重标**，不要沿用旧序号。
- **转写的「粒度」要单独判一次**（2026-10-02 国际贸易实测）：同一门课的不同批次可能由不同工具导出，粒度能差两个数量级——第三周那份 102 段、中位段长 41 秒，已近段落级；第四周那份 606 段、**45% 在 12 字以内**，是逐小句切分。判据就是这两个数：`≤12 字的段落占比` 与 `相邻段起点的中位间隔`。
  - 逐小句的那份**必须先合并再使用**。实测可用规则：相邻原始段起点间隔 **≤ 8 秒**且当前段落 **< 300 字** → 并为一段；
  - 段落时间码写成**区间** `[起–止]`，保留可回溯性（引用实录时给出区间即可，不必精确到秒）；
  - 不合并的后果：讲义里每句都独占一行，读起来是碎片，引用时也给不出有意义的上下文。
- **段间起点间隔 > 60 秒处记一条「语音间隔」标记**（`〔语音间隔 68 秒（01:17–02:25）：此处为看图/板书时间，无语音〕`）。这些间隔不是内容，但它们是**页与页推进的节奏证据**——老师停下来的地方，往往正是课件换页、看新图的位置。
- **跨章 / 跨讲拆分只按时间戳切，不按段号切**（2026-10-02 国际贸易实测，一次录音跨两讲）。做法三步：
  1. 在转写里找**章节边界的信号句**——上一章的收束句与下一章的开场句是**成对出现**的。实测原话：收束「好吧，这是这部分的内容」（37:07）＋ 开场「这是我们那个经典模型里面最后的一个模型」（37:29）；两句之间还有过渡句「我们后面这个讨论这个模型非常简单」；
  2. 取这两句的时间戳作切点（本例切在 37:07 / 37:10）；
  3. 切完**必须核对两侧的首段与末段**是否各自成篇——左片末段应是收束句，右片首段应是新话题的开场，不允许一侧以半句话结尾。
  - 同一次录音切出的两片，**文件头要互指**（`本片段共 37 分 7 秒；同一次录音从 37:10 起转入第五讲，已另存到 lecture five`），否则日后无法判断是否漏了内容。
- **拆分件必须带「内容地图」表**，字段：来源文件 / 录音时段 / 对应课件页码范围 / 章节归属 / 片段性质（是否从半截话开始）/ 转写质量 / **拆分依据**（哪句原话对应哪一页）/ 边界说明。拆分件是要被反复引用的素材，没有这张表，几个月后无从判断某段属于哪一页、依据是什么。
- **拆分时不要顺手删内容**：ASR 可疑段用 `〔转写疑误：含无关词，疑 ASR 幻觉〕` 标记、课堂行政段用 `〔课堂行政：…非知识内容，保留原文备查〕` 标记即可。**删改留给做讲义那一步**，素材阶段保持无损。
- 产出 `<讲次>_transcript_clean.md` + `<讲次>_transcript_index.md`（段号 | 时间码 | 前 N 字，供对齐时快速定位）

### (0b) 锚点对齐

从课件抽**锚点**：小节标题、专有名词、公式名、例子名、具体数字。
在转写里标出锚点位置，相邻锚点之间即为一个语义块，归入对应小节。

强信号优先级：**专有名词 > 公式名 > 具体数字 > 通用词**

产出 `alignment.md`（语义块 → 小节 + 命中锚点 + 置信度）。
**低置信度一律标 `?` 并归入节末补充**——错位比缺失更糟。

**注意**：音频没有画面信息，课件页号无从得知，只能靠语义对齐；**不要编造「对应课件第 N 页」**。

### (0c) 增量筛选

**先确定取材口径**（见 **第五节**）：

| 口径 | 做法 | 何时用 |
|---|---|---|
| **宽口径（默认）** | 课件要点与老师的讲解**一并融入正文**；覆盖率更高、篇幅更长 | **未指定时按此档**（2026-10-10 用户确认——实战口径） |
| **严口径** | **只取课件里没有的**，其余归 D 丢弃（约七成） | 用户明确要"只补充课件没讲到的" |

下面四分类按所选口径执行。

| 类别 | 判据 | 处理 |
|---|---|---|
| A 强调与考点 | "这个必考""考试就考这个""容易错在……" | 保留（凝练入正文或 `importantbox`） |
| B 口语化解释 | 用大白话、类比、生活例子把公式讲透 | 保留 → 课堂实录 |
| C 课件外补充 | 现实案例、行业数据、亲身经历、参考文献、跨章联系 | 保留 → 课堂实录 |
| D 冗余 | 念课件、闲聊、行政通知、点名、机械重复 | **丢弃** |

**唯一判据**：课件文本层（`pdftotext -layout`）能查到等价表述的，归 D。

### (5) 凝练融入（原「逐点缝合」）

> **2026-10-09 体例改版后，本步做法已变**：不再设实录框、不标时间码、不引原话。
> 旧做法（插入 `aiexplainbox[Lecture]` 并附时间戳）已废止。

对每一段老师的讲授，做四步（详见第五节「第二条铁律」）：

1. **找出这一段真正在讲哪个知识点**——他常常一口气说三四个意思，先拆开归类；
2. **把口语凝练成规范书面语**——「你想象一下对吧，这个就是说……」要变成一句完整的陈述句；
3. **放回正文该在的位置**——是解释就接在定义后，是证据就接在结论后，是反例就接在主张后；
4. **与课件内容合并成一段连贯叙述**——不要出现「正文说一遍结论、框里再重复一遍」的结构。

**两条保留的裁决规则**：
- **听不清处标 `（录音不清）`，绝不猜**；
- **与课件冲突时以课件为准**，并用 `warningbox` 写明「口述为 X、课件为 Y」。

**交付后必做两件事**：
- **时间码索引另存** `_src/timecode_index.md`（原框的位置／时间码／内容摘要）——正文不留时间码，但可回溯；
- **双向覆盖核对**（见第五节末）：老师知识点清单逐条检索 + 课件 `P1–Pn` 无缺号。

## 三、主线 B · 改造已有讲义

### 三·B1｜增量增补模式（已有 L1 讲义 + 局部录音）

**触发场景**：先前已交付过一份 L1 讲义（纯课件），之后才拿到**某个片段的**课堂录音，用户要求「只处理第 X 章 / 只处理某段范围」。这与 §三 的「从零双源」不同——**不是重建，而是在既有文件上分区增补**。

**必须先对齐的事**（用 AskUserQuestion，不要猜）：

1. **「章」的边界**——用户口中的「第二章 / 第三章」未必与课件页码一一对应，也可能指课件内部的某个主题分界。把候选边界摆成表让他选：

   ```text
   讲义 §7 产品评级模型       ↔ 课件 39–64 页  ↔ 转写 [001]–[068]
   讲义 §8 卖家评级           ↔ 课件 65–68 页  ↔ 转写 [069]–[078]
   讲义 §9 评级有效性         ↔ 课件 69–71 页  ↔ 转写 [079]–[087]
   讲义 §10 推荐系统与长尾     ↔ 课件 72–87 页  ↔ 转写 [089]–[119]   ← 若属下一章则不动
   ```

   用户给出的「录音从第 N 页开始」是**课件页码**，务必借助课件的逐页索引（`slides_index.md`）换算，不要拿讲义页数去对。
2. **承载方式**——老师的讲解**凝练成书面语写进正文**，按其位置并入对应小节（见 **第五节**）。
   **不设实录框、不标时间码**。
3. **输出方式**——**另存新文件**（如 `_notes_L2.tex`），原 L1 版完整保留，两份并存。

**执行要点**：

- 文件头注释写清四件事：**处理范围**（讲义哪几节）、**对应课件页**、**对应转写段与时间码范围**、「未处理范围原样保留」
- 只增补转写稿覆盖到的节次；未被覆盖的节次（录音开始之前的页）**保持不动**
- **转写稿末尾常有「下一讲预告」**（老师用下一讲课件做的引言，含新案例）。这属下一章，**整段排除**，不要写进讲义
- 老师**方向性口误**（不只是数字）也要标：如把「低质品估值低于成本」说成「高于」，用 `warningbox` 写明「以课件为准」
- 老师若在转折处给了**与课件不同的讲解顺序**，以老师的顺序为准，并在新加的小节标题里体现出来（不要硬塞进原有的小节结构）

**交付前必做的「未越界核验」**（硬证据，比人眼可靠）：

```python
# 以课件分界注释（如 "% ===== 第 7 章 ====="）切段，比对未处理区段是否逐字符一致
i_old, j_old = old.index(M7), old.index(M10)
i_new, j_new = new.index(M7), new.index(M10)
assert old[:i_old] == new[:i_new], "§1–§6 被越界改动！"
assert old[j_old:]   == new[j_new:], "§10–§11 被越界改动！"
```

同时统计并报告：**处理区净增字符数**、**新增 `[Lecture]` 框数与占比**（占比建议 ≤ 正文 1/3）、**盒子 begin/end 配对**。框数若明显超出用户预期，**如实报告实测值并请其裁定是否合并**，不要自行裁剪或掩盖。

### 三·B2｜旧体例改新体例（批改作业模式）

**触发**：一批旧讲义仍把老师的话整块放在实录框里，用户要求「按新体例重新生成」。
2026-10-09 全库改版（11 份、332 个实录框）即此模式。

**开工前先冻结基线**：`cp X_notes.tex X_notes.tex.bak`，并记录改前指标——
**页数／字符数／实录框数／时间码数／大点与分点数**。没有基线就无法证明"只改体例、不丢内容"。

**两种改写手法，按框的分布选**：

| 手法 | 适用 | 做法 |
|---|---|---|
| **整块替换** | 框少且集中（如一份里 12–15 个） | 按**框序号**遍历：定位 `\begin{aiexplainbox}[Lecture]` 到对应 `\end{...}`，整块换成新写的书面语段落。无需精确匹配旧文本，最稳 |
| **锚点替换** | 框多且分散（40–50 个） | 写 Python 脚本，逐条 `assert s.count(old) == 1` 再替换；**脚本末尾必须打印完成条数，并核对 = 总条数**（不等说明锚点抄错） |

**必做的三件验证**：
1. **越界核验**——无录音覆盖的章节必须原样保留：与 `.bak` 剥离标题与 structurebox 后**逐行比对，
   相似度应 ≈100%**，差异只能是刻意的标题归并；
2. **编译三零**——`^! ` / `Missing character` / `Overfull` 三个计数全为 0；
3. **时间码索引另存**——原实录框的位置、时间码、内容摘要写入 `_src/timecode_index.md`，
   正文不留时间码但可回溯。

**页数口径**：凝练口语与删除题外话会自然减页；参照《经济学研究方法合并版》的幅度（70→53 页，−24%），
**降幅明显超过该比例就说明有内容被误删，必须回去补**——不许靠删内容掉页。

**收尾**：更新进度总表「体例版本（新/旧）」列；按约定删除 `.bak` 备份。

## 四、结构变体

### 四·V1｜多课件合订模式（一次给同门课多个课件，要求合成一份）

**触发**：用户一次给出同一门课的**两个以上**课件，说「做成同一份」「合到一份里」。此时按 L1 或 L2 的单课件流程逐个做是**错的**——会得到若干份互不相干的讲义。

### 用户的核心要求（几乎一定会提）

> **「不要单纯罗列课件内容，要捋顺整个教材的逻辑。」**

这是合订模式与单课件模式的**根本差别**。单课件讲义的组织单位是"知识点"，合订讲义的组织单位是"**问题链**"。

### 落地手法三件套

1. **写一章「导言」**：交代这门课要回答的基本问题、解释路径（例如"国家差异"与"规模报酬"两条），并配一张**全课程逻辑地图**（TikZ 纵向流程图：现象层 → 描述层 → 解释之一 → 解释之二 → 政策层）。这张图是全书的地标，值得反复打磨。
2. **每讲开头的 `structurebox` 固定写三段**：
   - 本讲在**整条逻辑链上的位置**（是现象层？描述层？解释层？）；
   - **内部推进顺序**（照抄课件"计划"页即可，不要自创）；
   - **本讲留下的问题**（一句问句，指向下一讲）。
3. **写一章「结语」**：回到导言提出的问题**逐条作答**，再画一张**理论谱系图**（如按要素流动性排列：李嘉图/长期 — H-O/长期 — 特定要素/短期），明确标出本讲义覆盖了哪一段、未覆盖哪一段。

### 找「问题链」的正确位置——课件自己通常已经写好

**先找每一讲的收尾页与下一讲的开场页**，把"上一讲留下的问题 → 下一讲的回答"对齐。这比自造逻辑更忠实，也更容易得到用户认可。国际贸易实测：

| 讲 | 收尾留下的问题（课件原文） | 下一讲如何接 |
|---|---|---|
| 一 | 什么导致贸易增长？为什么贸易模式是这样？ | 二：先把事实量出来 |
| 二 | **什么理论可以解释我们看到的贸易模式？** | 三：李嘉图模型 |
| 三 | 缺点清单第 2 条：**所有人都从贸易中收益** | 四：特定要素模型 |
| 四 | 特定要素模型是李嘉图模型的**反面**、是**短期**模型 | 指向 H-O 与长期 |

### 技术要点

- 用 `\part` 分讲。`ctexart` 中 **`\part` 不重置 section 计数**，section 全篇连续编号——便于全篇交叉引用（"见 §14"），目录里 `\part` 只起分组作用。这是想要的效果，不要"修"成每讲重新编号。
- 输出：`<课件目录>\讲义\<课程名>_讲义.tex` + `.pdf`
- 中间产物：`讲义\_src\`，把**每个课件的全文按页提取**成 `L1_text.txt`、`L2_text.txt` …（`pypdfium2` 的 `get_text_range()`，保留 `[[PAGE n]]` 分隔）。后续写作与逐页核对都以此为准。
- **篇幅预期要放低**：PPT 要点式课件（每页几十字）即使按"详尽"展开，信息量也有上限。实测 147 页课件 → 精炼版 58 页。向用户报价时给区间而不给点估计。

### 开工前必须对齐的五项（照单问，不要替他决定）

1. **推进方式**：一次做完四讲，还是先做一讲样板再批量？
2. **展开程度**：详尽（逐页展开）还是精炼（合并同类页）？
3. **行政页处理**：课件开头的课程信息页（教材、考核、教师联系方式）收不收、收到什么粒度？
4. **插图策略**：理论图 TikZ 重绘 / 数据图 pgfplots 重绘 / 信息图与照片截图——明确各占哪一类。
5. **输出路径与文件名**。

### 四·V2｜单讲双源 + 逻辑衔接四件套

**触发**：用户给**一个讲次**的课件 + 该讲的课堂录音转写，要求「重新制作这一讲的讲义」；
且常同时提出一条硬要求——**「PPT 原有页面之间逻辑过渡不明显，请结合老师的讲解思路呈现衔接」**。

这就是普通的 L2 双源流程，但多出「衔接」这一层交付物。落地成**四件套**：

1. **开篇（不编号的导言节）**
   - 一个 `structurebox` 写「本讲要回答什么」，内含**三条线索**（框架线 / 目标线 / 工具线）；
   - 一张**全讲逻辑地图**（TikZ 纵向链，每格一个里程碑，右侧可挂课件页码）。图要能一眼看出
     「问题 → 工具 → 暴露缺口 → 补足工具 → 回到实践 → 下一讲」的走向。
2. **每一节开头的 `structurebox` 固定三段**：本节在逻辑链上的位置 / 内部推进顺序 / 本节留下的问题。
   第三段尤其重要——它让下一节「非来不可」。
3. **节与节之间的过渡由老师的讲解顺序承担**：老师在课上说的「我刚刚讲完那些之后，我们接下来……」
   就是最好的路标——把它**凝练成一句书面语的过渡句**写进正文（或脉络表的第三列），
   让「为什么从 A 跳到 B」有依据，而不是由讲义的作者硬编。**不保留原话、不标时间码**（见 **第五节**）。
4. **结语节**：回到开篇的问题**逐条作答**（三问三答之类的形式），再收一个「本讲小结」——
   重点 / 必记公式 / 易错点三件。

**录音整合的三条硬要求（2026-10-09 改版）**
- **不报页数目标**：写完是多少就是多少，**不为自己报出的区间补内容**；
- **老师的讲解全部凝练成书面语融入正文**（见 **第五节**）：不设实录框、不标时间码、不引用原话；
- **课件没有但老师讲了的**（现实例子、政策算例、人物与文献、机制解释、判断准则）**一条都不能丢**，
  按其性质落进正文或 `importantbox` / `knowledgebox` / `warningbox`；
  口述数字与课件不一致时以课件为准，并在 `warningbox` 里写明哪一部分是可确认的。

**四件套的落地格式（2026-10-02 实测补录，避免各写各的）**

用户对「割裂」的容忍度很低，会明确要求「把每一页 PPT 之间的关联写入讲义」。**光有四件套不够，还要做小节级承接**。三层一起做才不割裂：

| 层级 | 位置 | 写法 |
|---|---|---|
| **章间** | 每个 `\section{}` 之后的第一段 | 说明与上一章的关系；**有录音时直接引老师原话并放实录框**（如「低质商家越难长期不被揭露。那这个卖家评级同时治理两类问题……」） |
| **小节间** | 每个 `\subsection{}` 之后的第一句 | 一句承接 + 页码标记，格式：`{\small\itshape【承上｜课件 p41--p42】}\quad …` |
| **章内导航** | 每个 `\section{}` 之后的 `structurebox` | 严格三段：`\textbf{在逻辑链上的位置}：…\\[1.5mm]`、`\textbf{内部推进顺序}：…\\[1.5mm]`、`\textbf{本节留下的问题}：…` |

**三个必须遵守的排版细节**（都是实测踩出来的）：

1. **`structurebox` 必须放在 `\section{}` 之后，不能放在之前**。若放在之前，PDF 里会出现「页眉章节名 → 居中『本节知识体系』→ 框 → 章节标题」的倒序，读者先看到导航才知道这是第几节。
2. **三段之间要用 `\\[1.5mm]` 显式加行距**。`ctexart` 的 `\parskip` 为 0，光靠空行分段三段会紧贴在一起。
3. **承接句前缀不要写成模板填充**（如「（承接：与上一小节的关系，课件 pXX）」读起来像占位符），用紧凑标记 `【承上｜课件 pXX】` 即可。
4. **`structurebox` 三段之间的换行加距必须写 `\\[1.5mm]`，写成 `\[1.5mm]` 会当行间公式**，报
   `Display math should end with $$`，而**错误行号指向的是后面带 `$...$` 的那一行**，极易误判。
   批量修正时**不能用简单 replace**——`\\[1.5mm]` 里含 `\[1.5mm]` 子串，会把已正确的也改坏；
   要用负向断言 + lambda：`re.sub(r'(?<!\\)\\\[1\.5mm\]', lambda m: '\\\\[1.5mm]', s)`。

**「回指标记」是最容易被洗掉的东西**——老师课上的「扣 back，我们上节课讲的这个内容」「因为前面一页 PPT 怎么说的？」「有点像上上节课讲的网络效应」这三类句子，是页与页、节与节逻辑链的**直接证据**。做讲义时若只用对照表把内容组织起来、把这些标记删掉，读者就看不到「为什么从这页跳到那页」。**要原样保留并标时间码。**

#### 四·V2a｜页级脉络与零遗漏（2026-10-02 用户明确要求）

用户在投资学 6\&7-3 交付之后，提出了比「四件套」更高一档的要求，原话：

> 「第一，梳理整份 PPT 的整体逻辑脉络，包括页面与页面之间的衔接与切换逻辑（例如第 1 面与第 2 面、第 31 面与第 32 面之间的关联），这些逻辑需要**从我的录音中提炼**得到；第二，**课件中已有的内容，讲义里必须完整保留**，同时把老师上课补充的内容写进去，尤其是课件上没有、老师单独讲解的部分，也要补入讲义，确保讲义覆盖**录音中体现的逻辑线和课件内外的全部要点**。」

**含义：章间 + 小节间两级衔接不够，必须做到第三级——页与页之间。** 三个落地件：

#### 落地件一：课件页面推进脉络表（放导言，紧跟全讲逻辑地图之后）

一张逐页表，三列：

| 课件页 | 这一页讲什么 | 为什么转到下一页（录音中的过渡逻辑） |

- 第 2 列让读者逐页核对「课件有没有被讲漏」；
- **第 3 列是本表的灵魂**——它回答「为什么讲完 A 就跳到 B」，这是幻灯片看不出来的部分，**必须从录音的过渡句提炼**（老师的「那我们接下来…」「所以到现在我们…」「在这个问题之后…」）；
- 连续多页讲同一件事时，第 3 列写「承接上页」，不要硬编。
- 表后附 `notebox` 说明「这份表怎么用」（核对遗漏 / 看推进逻辑 / 快速定位）。
- 实测体量：30 页课件 → 表约 2.5--3 页。

#### 落地件二：逐页衔接标记（成体系覆盖全部内容页）

正文里按页序插入

```latex
{\small\itshape【承上｜课件 pXX $\to$ pYY】}\quad …一句话说明为什么转到下一页…
```

实测 30 页课件覆盖 19 处。两种特殊标记：

- `【关于顺序｜课件 pXX 在 pYY 之后】`——当讲义为教学清晰而**调整了课件顺序**时，必须显式说明为什么调整，并给出交叉引用（例：解析解在课件里排在图解之后，讲义前置了它，就要写明「两条路径给出同一个 $y^*$，交叉验证见 \S3.3」）；
- `【承上｜课件 pXX $\to$ pYY $\to$ pZZ】`——连续多页属同一件事时合并标记。

#### 落地件三：零遗漏双向核对（课件侧 + 录音侧）

**课件侧**：PPT 的**每一页**都要能在讲义里找到落点。
- 空页 / 纯配图页也要在脉络表里标「（图形页，无正文）」并说明承接哪一页——**不许留白页不解释**；
- 若某页在 PDF 文本层只有标题（如「图 7.9 最优组合的成分」），按标题与上下文整理其含义，**并在 `notebox` 里声明「具体图形请对照原课件，讲义不臆造图内细节」**；
- 「目录页 / 进度表页」不要当成废页丢掉——它们正是**老师自己的推进路标**（哪一项标了「完成」、下一项是什么），要写进脉络表。

**录音侧**：转写中**能确认的要点都要有落点**。
- ASR 质量差的段落，**能确认多少写多少**，并在该节用 `notebox` 声明「本节录音质量较差，只收录能与课件相互印证的内容」；
- **不可确认的绝不猜写**，但要在**交付报告里如实说明漏了什么**，不要默默跳过；
- 课间闲聊与行政通知仍按原规则整段剔除，**剔除动作本身要在报告里交代**。

#### 与「完整 ≠ 逐字」的关系（别把两条规则读成对立）

「完整」指的是**要点与逻辑线不缺**，「不搬转写稿」指的是**不逐字搬运**。二者不矛盾：

| 要做的 | 不要做的 |
|---|---|
| 课件每一页有落点 | 把幻灯片文字原样复制成段落 |
| 老师补充的案例、数据、判断、口头解释全部进讲义 | 把口语碎句、语气词、重复三遍的话原样堆进正文 |
| 逻辑转场用老师原话（带引号 + 时间戳） | 把「接下来我们讲 X」改写成书面腔后丢失课堂感 |

#### 见效顺序（实测）

先建脉络表 → 再按表逐页查漏 → 补上漏掉的页 → 最后成体系插入衔接标记。先写衔接后查漏会返工。

#### 四·V2b｜「一次讲次只录到一半」怎么处理


常见情形：课件 68 页，但本次课堂录音只覆盖 p3–p35。用户可能的裁定是两种之一，**必须先问清**：
① 只做有录音的前半讲；② 做整讲，有录音的部分详写、其余依课件整理并标注待补。
若选 ②（用户本次的选择），落地方式：

- **封面副标题写明覆盖率**，例如「§1--§4 依据课堂录音整理；§5--§8 依课件整理，待录音增补」；
- **每个无录音的节开头放 `notebox[Note：本节录音未覆盖]`**，一句话说清"依课件整理，待录音到位后按同一体例补充"；
- **节结构要让录音边界落在两节之间**，不要切在一节内部——这样读者一眼能看出哪里是双源、哪里是单源；
- 无录音的节仍要写足：公式、推导、数值例、结论、易错点一项不少，只是没有老师的原话与案例；
- 交付时**明确告知用户哪些节待增补、以及增补需要什么素材**（通常是下一次课的录音）。

**两个必踩的坑**

- **不要用自定义宏包实录框**（例如先定义 `\lec{...}` 再写正文、事后用脚本展开成正式环境）。
  脚本展开时若只替换前半段，会留下**多余的 `}`**，编译报 39 处 `Extra }` 而页面仍能出，
  极易漏检。**直接写显式环境**（`aiexplainbox` 的 `[Lecture]` 形式），既好计数，也不给后续埋雷。
- **交付后按用户要求删除过渡产物时，`figures/` 必须留下**——截图是编译必需的资源，不属于中间产物。
  该删的是：提取的课件文本、解析脚本、渲染核对用 PNG、以及 `.aux/.log/.out/.toc`。

## 五、内容规范：老师的课怎么用（长期约定）

> **这一版推翻了此前「实录框原话优先」的写法。** 用户对手上所有讲义提出同一批评：
>
> **「讲义内容本质上是老师课堂话语的转录，而你的处理并不理想。我的要求不是把老师原话直接照搬到讲义里，
> 而是要把老师的话凝练成核心观点或重要观点，用规范的书面语表达出来……不要把老师的话一块一块原样堆放，
> 导致上下无衔接、缺乏上下文而显得毫无意义。你应当把老师的话自然地融入教材，使其成为连贯、有条理的正式内容。」
>
> 一句话：**老师的话是「材料」，不是「成品」。**

### 第一条铁律：取消实录框

- **全篇不出现 `aiexplainbox[Lecture]`**，一个也不留。
- **正文不出现「老师说」「老师讲」「课堂实录」「老师举了个例子」这类转述口吻**，直接陈述。
- **不标时间码**。正文里既不出现 `[43:12]`，也不出现「（第二次课 01:02:16）」这类出处痕迹。
- **不引用原话**（引号只用于术语与概念，例如「可操控性」「前定变量」）。

### 第二条铁律：凝练 → 融入，而不是搬运

对每一段老师的讲授，做四步：

1. **找出这一段真正在讲哪个知识点**——他常常一口气说三四个意思，先拆开归类；
2. **把口语凝练成规范书面语**——「你想象一下对吧，这个就是说……」要变成一句完整的陈述句；
3. **放回正文该在的位置**——它是解释就接在定义后，是证据就接在结论后，是反例就接在主张后；
4. **与课件内容合并成一段连贯叙述**——不要出现「正文说一遍结论、实录框再把同一件事说一遍」的重复结构。

**唯一的例外是判断类内容**：老师给出的、课件上没有的经验法则或主张（例如「十个特征里九个不平衡，
这个 RCT 就作废了」），用 `importantbox` 承载，**仍写成书面语**，只是明确它是一个判断而非定理。

### 第三条铁律：题外话一律删

**直接删除，不进正文、不进附录**：

| 类别 | 判定 | 例子 |
|---|---|---|
| 个人经历与家庭生活 | 与知识点无关 | 「我自己也有女儿也有儿子……先把弟弟揍一顿」 |
| 学生互动 | 点名、提问、举手、集体应答 | 「来自客家的同学举个手」 |
| 玩笑与闲谈 | 只为活跃气氛 | —— |
| 课堂行政 | 点名、放假通知、作业与考试安排 | —— |
| 纯粹的自我指涉 | 「我当年」「我朋友」 | 除非它本身是教学案例的组成部分 |

**但下列内容必须保留**（属于知识，不属于题外话）：老师补充的现实案例、政策算例、文献与人名、
数据与数量级、机构与制度背景、行业内幕式的机制解释、对某个做法的批评与理由。

### 第四条铁律：老师补充的知识点一个都不能少

凝练掉的是**口语与题外话**，不是**内容**。改完之后必须做一次**逐项核对**：
把老师课上讲过的知识点（案例、人名、数字、机制、判据）列成清单，逐条在新稿里检索确认。
**「关键词 0 命中」不等于没讲**——ASR 会把专名写错，必须回看上下文人工判。

### 第五条铁律：能表格化就表格化

老师口述的**对比、分类、条件、并列项**，凡呈「列举」形态的，一律改成正式表格：

- 例：「双胞胎的五个差异来源」→ 三列表（差异来源 / 机制 / 影响）；
  「控制能力的三条路」→ 三列表；「内部有效性的两个假设」→ 两列表；
  「四类随机化」→ 对照表；「诺奖年份与方法」→ 对照表；「实验处理臂」→ 设计矩阵表。
- 判据：**读者需要横向比较的，就该是表**；顺次推进的论述才用段落。

### 第六条铁律：图表以课件原图为主

- **课件上有的图与表，优先用课件原图**（300 dpi 渲染后裁掉演示软件工具栏，`\includegraphics` 引入）。
- **课件上没有的图不另外画**，口述内容用文字或表格表达。
- **例外一：内容性图表可重绘**——原图是位图、模糊、含不合规内容的，用 TikZ / `booktabs` 重绘。
- **例外二：导航性图示保留自绘**——全课程逻辑地图、页级推进脉络表、理论谱系图是讲义自己的导航件，
  不是知识点图表，继续用 TikZ 绘制。
- 国别表格与地图：**一律不截图**，改 `booktabs` 重排（中国台湾、中国香港按单独关税区标注）。

### 保留不动的骨架

改版只动「老师话语这一层」，下列件照旧保留：

- 每节开头的 `structurebox` 三段式（在逻辑链上的位置 / 内部推进顺序 / 本节留下的问题）；
- 页级 `【承上｜课件 pXX → pYY】` 标记与课件逐页推进脉络表；
- `importantbox` / `knowledgebox` / `warningbox` / `notebox` / `examplebox` 的使用方式；
- 各节小结、附录考点速查与易错点清单。

### 大纲层级：大点要少、分点归位（2026-10-09 用户要求）

用户原话：**「减少大点数量……将原本过于分散的小点进行合并归纳，重新组织为有明确层级的分点，
并将其嵌入到对应的大点之下，形成清晰连贯的逻辑链。」**

**硬指标**：

| 层级 | 用什么命令 | 数量要求 |
|---|---|---|
| 篇 | `\part` | 2--4 个 |
| **大点** | `\section` | **正文大点 ≤ 10 个**（导言／小结／结语／附录另计） |
| 分点 | `\subsection` | **每个大点 2--6 个**，不得超过 7 个 |
| 细点 | `\subsubsection` | 仅用于确有必要再切一层时；`\paragraph` 接排标题不要用（会与 `【承上】` 挤在一行） |

**做法**：

- **先列新大纲再动手**：把现有同级标题按主题归并，写出「大点 → 分点」两级清单，核对分点数是否落在 2--6；
- **只改标题层级与分组，正文一个字都不删**——归并是靠分组，不是靠删减；
- **structurebox 随大点走**：每个大点一个三段式（`内部推进顺序` 段直接列出它的分点），
  不再每个小节一个；
- **目录只到大点**：`\setcounter{tocdepth}{1}`，让目录一页读完、一眼看清脉络；
  分点靠正文编号（2.1 / 2.2 …）与大点 structurebox 里的清单位置呈现；
- **篇级导言用 `\section*` + `\addcontentsline`**，不占编号但进目录。

**交付前必做的自检**（脚本化）：

1. 统计 `part / section / subsection / subsubsection` 四个层级的数量，逐个大点列出分点数；
2. **剥离全部标题与 structurebox 后，新旧正文必须逐字符一致**（`difflib` 比对，差异应为空）——
   这是「只改结构、内容零丢失」的唯一可信证据；
3. 修掉因重编号而失效的硬编码交叉引用（形如「第 8 节」「第 11 节」），改用 `\ref{}` 或写成带小节的号（8.3）。

## 八、技术坑清单

> 全部来自实测。改讲义前扫一遍，能省掉大半返工。

| # | 坑 | 症状 | 处理 |
|---|---|---|---|
| 1 | **`\\[1.5mm]` 写成 `\[1.5mm]`** | 报 `Display math should end with $$`，**错误行号指向后面带 `$...$` 的那一行**，极易误判 | 批量修：`re.sub(r'(?<!\\)\\\[1\.5mm\]', lambda m: '\\\\[1.5mm]', s)`——**不能简单 replace**，会把已正确的也改坏 |
| 2 | **heredoc 吞反斜杠** | 用 shell heredoc 写含 LaTeX 的脚本，`\\` 变成 `\`，锚点全部失配 | 含 LaTeX 的替换**一律用 Write 工具写 `.py` 文件再用 Python 执行** |
| 3 | **`\section*` 不更新页眉** | 星号节（导言、附录）的页眉一直停留在「目录」 | 在 `\section*` 后补 `\markboth{...}{}` |
| 4 | **`\small` 位置** | 报 `Misplaced \noalign` | 不能放在 `\begin{longtable}` 与 `\toprule` 之间，须放在首个 `\toprule` 之后 |
| 5 | **Python 相邻字符串自动拼接** | `r"…}"` 换行接 `r"\addcontents…"` 会合成一行 | 显式写 `+ "\n" +` |
| 6 | **pdftotext 对图片型课件无效** | 课件按页提取只有零星文字 | 图片型页改由「页级脉络表 + `【承上｜课件 pXX】` 页码标记」两条链覆盖 |
| 7 | **下标变量被连写** | `a_{PL}^C` → `aPLCC`、`r\cdot a_K^C` → `raKC`，核对时误报"零命中" | 核对脚本要加**词根匹配**；人工确认后用 LaTeX 形式记录 |
| 8 | **docx 读不全** | 走编辑器通道只能拿到每段 ≤200 字预览 | 回落 Python 解析 `word/document.xml`；`transcript_kit.py extract` 已内置 |
| 9 | **说话人号与时间码粘连** | `说话人210:36` 若用贪婪 `(\d+)` 会读成「21 + 0:36」（实为 10:36），**时间戳整体错乱且表面正常** | 正则用 `(?:说话人\|发言人\|Speaker)\s*(\d)[\s\u3000]*(\d{1,2}:\d{2}(?::\d{2})?)`；**用"时间码是否单调"验伪** |
| 10 | **时间码分段重启** | 同一次课的几节录音各自从 00:00 计时，取「末−首」得负值 | 分段累加（`transcript_kit.py` 的 `total_duration()`）；讲义里按组插 `〔转写重启 N/组数〕` |
| 11 | **Bash 长命令链被截断** | 一长串 `&&` 跑到一半被 SIGTERM | 拆成多条命令 |
| 12 | **原生程序路径** | Windows 下 `pdftotext` 找不到 | 写 `D:/texlive/2025/bin/windows/pdftotext.exe` 这类**绝对路径**，或把目录加进 `PATH` |

### 九·2｜商科语境（不预设课程，按课件内容判定）

覆盖范围与常见核心内容（示例，非穷举）：

- **金融/投资**：期望收益与方差、有效前沿、CAPM、APT、债券久期与凸性、期权定价（二叉树 / Black-Scholes）
- **公司财务/会计**：三张报表勾稽、财务比率、WACC、资本结构、股利政策、估值（DCF / 相对估值）
- **平台经济/产业组织**：双边市场、网络效应、Rochet–Tirole、Metcalfe 定律、管道 vs 平台、定价结构
- **管理/营销**：4P、波特五力、商业模式画布、客户生命周期、渠道与定价策略
- **经济学**：供需与弹性、消费者/生产者剩余、博弈论、市场结构、外部性
- **商务统计/计量**：假设检验、回归、面板数据、内生性、工具变量

**建模约定（通用）**

- 收益率用对数还是简单收益须**显式声明**
- 无风险利率、时间单位、离散/连续复利须统一
- 符号表在首次出现处给出，全文一致
- **术语中文为主 + 英文括注**：有效前沿（efficient frontier）、久期（duration）、双边市场（two-sided market）

课件内容跨多个领域时，以课件主线为准。
