# lecture-notes-zh（中文讲义结构与教学叙述）

本 skill 负责流水线的**组织层**：把课件知识点、详细推导、例题，编排成一份读起来像"好老师带读"的中文讲义。

## 一、教学序列原则

每一节都按这个顺序推进：

1. **动机**——为什么要有这个概念？它解决什么问题？
2. **直觉**——先用平实语言讲清大致图景。
3. **机制**——它怎么运作？关键量如何联动？
4. **形式化**——在直觉之后才引入数学记号与定义。
5. **例子/证据**——用例题、数值或图表落地。
6. **Takeaway**——这段应该记住什么。

**不要**按幻灯片顺序罗列；要重写成有意图、有对比、有铺垫的教学序列。逻辑转折处要耐心、讲明"为什么这里要引入这个概念""它解决了什么""下一步为什么自然接上"。

**深度与可读性并重**：保持技术深度，但形式化一律放在直觉之后。某节密度过大时，**拆成递进的子节**，而不是把长推导压成一团。

## 二、默认章节结构（8 段）

1. **主题与学习目标**——本讲解决什么问题；学完应掌握什么；适合什么基础的读者。
2. **背景与动机**——为什么研究它；它在学科体系中的位置；与已学内容的联系。
3. **基本概念与模型**——研究对象、关键量、关键假设、模型边界。
4. **主线推导与分析**——按逻辑顺序展开；每步说明依据；对长推导分段命名；点出关键转换点与常见误区。（推导细节交由 `rigorous-derivation`，此处只负责编排与叙述）
5. **结果总结**——核心公式、核心结论、适用范围、含义。
6. **典型例子与应用**——至少一个具体例子建立直觉（例题、数量级估算、特殊极限、真实场景）。**只能用课件里已有的例子**，不得自造。（例题正文交由 `exam-problems`）
7. **常见错误与易混点**——最易误解之处，并解释为什么容易错。
8. **复习提纲**——本讲重点、必记公式、需理解的逻辑、可继续追问的方向。

## 三、叙述风格

- **中文**为主，关键术语英文括注。
- 写成**讲义**，不要写成聊天口吻，也不要写成论文。
- 公式清晰，不要全压成一句；必要时用小标题分层。
- 重点强调**"为什么"**。
- 不要出现"课件指出""PPT 中提到"之类转述腔。
- 避免空泛的高层表述；一切论断都落到具体机制、例子、变量、步骤上。
- 避免"不是……而是……"滥用，除非确有真实对比且能澄清机制。
- 可枚举内容一律转为列表/编号，不写成大段文字。

## 四、教学信号盒子

| 环境 | 用途 |
|---|---|
| `importantbox` | **核心结论**：形式定义、中心论断、关键机制小结、定理式陈述、算法关键步骤、密集讲解后的紧凑重述 |
| `knowledgebox` | **背景与旁支**：前置提醒、历史脉络、工程语境、设计权衡、术语对比、建立直觉的类比 |
| `warningbox` | **易错与坑**：记号超载、隐藏假设、误导性启发式、易犯的实现错误、因果混淆、off-by-one 类推理错误、以及"错误直觉 vs 正确直觉"的对照 |

规则：

- **没有"每节一个框"的配额**。材料里有多少个不同的教学信号，就放多少个框。
- 每个框都要有**具体的教学载荷**，不是泛化强调，更不是装饰。
- 框紧跟在**激发它的那段正文/推导/例题之后**。
- 常规叙述留给普通正文；框只用于高信号要点。
- **框内不放图。**

```latex
\begin{importantbox}[Core]
...
\end{importantbox}

\begin{knowledgebox}[Context]
...
\end{knowledgebox}

\begin{warningbox}[Pitfall]
...
\end{warningbox}
```

## 五、章节收束

- **每个主要小节**以 `\subsection{本章小结}` 收尾，包含：本讲重点 + 必记公式 + 需理解的逻辑 + 易错点。
- 有值得外链时补 `\subsection{拓展阅读}`（1–2 条）。若无，省略，不要硬凑。
- 全文末尾可加 `\section{总结与延伸}`：核心主张与机制的结构化提炼、跨节串联、谨慎的一般化、以及可继续追问的方向。

## 六、篇幅档位

未指定时按"**中等详细度**"：体系完整、推导不过度压缩、不故意写成论文、保留教学性解释。

按用户指定调整：

| 用户说 | 调整 |
|---|---|
| 本科生可读 | 加强背景与数学动机 |
| 竞赛/进阶风格 | 突出技巧、结构与直觉 |
| **尽量详细** | **展开中间步骤，不省略关键过程**（= 与 `rigorous-derivation` 的 L2/L3 联动） |

## 七、与其它 skill 的接口

- 推导的**细节**由 `rigorous-derivation` 提供，本 skill 只负责把它嵌进教学序列并写承接句。
- 例题的**内容**由 `exam-problems` 提供（只收录课件原题），本 skill 负责在合适的教学位置引出它；课件未给例题的方法**不要把例子强行补上**，把方法讲清即可。
- 课件的**原文边界**由 `courseware-notes` 保证（黑字 vs 蓝框），本 skill 不得越界把 AI 内容写成课件原文。

## 八、输出

默认输出**讲义正文的 LaTeX 片段**（`\section` / `\subsection` / 列表 / 展示数学 / 上述盒子），供 `courseware-notes` 填入模板。
