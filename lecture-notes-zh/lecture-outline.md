# lecture-outline.md —— 讲义大纲模板与长文组织

本文件供 `lecture-notes-zh` 在组织长文、控制结构、补复习提纲时读取。

## 一、讲义大纲模板（8 段式）

```markdown
# [主题] 讲义

## 学习目标
- [ ] 目标 1
- [ ] 目标 2
- [ ] 目标 3

## 前置知识
- 需要先掌握：……

## 大纲
1. 背景与动机（约 X 分钟）
2. 核心概念 A
3. 核心概念 B
4. 数学框架 / 主线推导
5. 典型例子与应用
6. 常见错误与易混点
7. 本章小结
8. 复习提纲
```

## 二、每节内部的六步教学序列

```
动机 → 直觉 → 机制 → 形式化 → 例子/证据 → Takeaway
```

- **动机**：为什么需要它？解决什么问题？
- **直觉**：先用平实语言讲图景
- **机制**：它怎么运作，关键量如何联动
- **形式化**：此时才引入记号与定义
- **例子/证据**：例题、数值、图表落地
- **Takeaway**：这段要记住什么

## 三、长文组织规则

1. **先骨架后血肉**：先定 `\section` / `\subsection` 两级骨架，确认无遗漏再填内容。
2. **一级节数量守纪律**：课件的子节不要升格为一级节。课件有 3 个一级节，讲义就大约 3 个 `\section`（外加星号的"本节知识体系"）。
3. **密度过大就拆**：某节内容过载时，拆成递进的子节，而不是把长推导压成一团。
4. **推导断点要标注**：交给 `rigorous-derivation` 处理，此处只留承接句与落点。
5. **可枚举内容一律列表化**：类型、性质、步骤、条件、成分、优缺点 → 编号或项目列表。
6. **每节收束**：`\subsection{本章小结}` = 本讲重点 + 必记公式 + 需理解的逻辑 + 易错点。

## 四、复习提纲模板

```latex
\subsection{本章小结}
\begin{itemize}
  \item \textbf{本讲重点}：……（3–5 条）
  \item \textbf{必记公式}：……
  \item \textbf{需理解的逻辑}：……（而非死记）
  \item \textbf{易错点}：……
\end{itemize}
```

## 五、检查清单

- [ ] 两级骨架无跳级、无孤立单条子节
- [ ] 每节都按六步序列推进，无"上来就抛定义"
- [ ] 无转述腔（"课件指出""PPT 中提到"）
- [ ] 每个 `\section` 末端都有本章小结
- [ ] 全文末尾有 `\section{总结与延伸}`（可选，但需有实质内容）
