## 三、回归中发现并修复的 3 个真 bug（工具的价值所在）

1. **切分误归左片**：无时间码的段（幻觉段、纯正文段）sec=-1，按秒数比较会全部落进左片 → 改为**按段序切分**；
2. **「发言人1　01:06」格式不识别**：原正则只认「说话人」，导致世界发展两份转写时间码全丢 → 扩展为
   `(?:说话人|发言人|Speaker)` + 全角空格；
3. **时长被时间码重启算错**：世界发展 lec2 是同一次课两节录音拼接、各自从 0 计时，直接取「末-首」得负值
   → 新增 `total_duration()` 分段累加；**该结构由 `probe` 自动检出**（第 45→48 段 41:10→00:24）。

## 四、能力边界（诚实声明）

- `detect`/`quality` 基于**词表与形态规则**，只能抓**词汇层面**的幻觉（司法语汇、中英混排破碎）；
  **语义层面的讹写**（英文句子被听错成另一个句子，如 lec2 的 "My love is sufficiency"）抓不到，
  必须人工抽查一段正文 —— 报告里已内置这条免责声明。
- 「可用率」是**估计值**，用于决定投入策略（L2 主导 / 部分 / L1 主导），不作为最终结论。
- 过短段落不再计为异常（那是**粒度**问题），改由 `probe`/`quality` 的「粒度」字段提示是否需 `merge`。
