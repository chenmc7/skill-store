# 逐步推导（rigorous-derivation）

对目标结果做严格、可跟随的逐步推导，产出自足、可核验的推导文本。

## 一、推导档位

由调用方（编排层）指定；未指定时**默认 L2**。

| 档位 | 名称 | 粒度 |
|---|---|---|
| L1 | 概要 | 只保留关键思路与关键方程，跳过常规代数 |
| **L2** | **逐步推导（默认）** | **每个实质性操作单独成步并标依据；纯代数恒等变形（展开、合并同类项、移项、代入）可合并为一步，但必须显式标注「代数化简」** |
| L3 | 全展开 | 每一步恒等变形都单独写出，不合并任何操作 |

> L2 的判据：**凡是"需要读者想一下为什么能做"的操作，都必须单独成步**；凡是"机械照做就行"的化简，可合并但要点名。

## 二、输入

- **必需**：待推导的目标（公式、不等式、定理、关系式）
- **必需**：起点（公理、假设、模型设定、已知命题）
- **可选**：证明手法偏好（直接、反证、归纳、变分、构造）
- **可选**：需遵循的记号约定（贴合指定教材）
- **可选**：可径引不必重推的已知中间结论

## 三、五步流程

### 第 1 步：写清"推导契约"

在动笔计算前先声明：

1. **假设与前提**：逐条列出。金融/经济类须写明：市场设定（完全竞争/无摩擦/无套利）、效用或偏好假设、时间与信息结构、变量取值范围。
2. **目标结果**：用精确记号陈述。等式写两边，不等式写明方向与取等条件。
3. **适用范围**：明确成立条件与不覆盖的情形。
4. **符号表**：定义每个将出现的符号（含单位或量纲）。

```markdown
## 推导契约
- **起点**：[假设 / 公理 / 已知结果]
- **目标**：[精确的数学陈述]
- **适用条件**：[限制与假设]
- **符号**：
  - [符号]：[含义]，[单位]
```

**失败处理**：若目标含糊或前提不全，先澄清再推。含隐藏假设的推导不可靠。

### 第 2 步：清点所需数学工具并核验适用性

1. **代数**：张量/矩阵运算、求和与乘积、级数展开；核验前提（可逆、收敛）。
2. **微积分与分析**：常/偏微分、积分（及积分域）、泛函导数、条件期望；核验正则性（可微、可积、可交换求导与期望）。
3. **优化**：拉格朗日乘子、KKT、比较静态；核验约束资格与二阶条件。
4. **概率与随机**：期望/方差运算律、协方差代数、条件期望迭代律、伊藤引理（如涉及连续时间）。
5. **待引恒等式**：逐条写出并具名，供后文 `[by {恒等式名}]` 引用。

```markdown
## 数学工具箱
- **代数**：[技法与前提]
- **分析**：[工具与正则条件]
- **优化**：[约束与二阶条件]
- **待引恒等式**：[具名列出]
```

**失败处理**：某工具前提未核验（如未证一致收敛就逐项求导）→ 标记为缺口，或补证，或降格为附加假设。

### 第 3 步：执行推导（逐步 + 逐步标依据）

1. **一步一操作**：每个编号步只做一个实质性操作，不合并多项操作。
2. **依据标签**：每步标注来源，常用标签——
   - `[依据：假设]` — 引用已声明的假设
   - `[依据：定义]` — 使用先前定义
   - `[依据：{恒等式名}]` — 如"由协方差双线性"
   - `[依据：第 N 步]` — 引用本推导内前面的步骤
   - `[依据：{定理名}]` — 引用第 2 步列出的外部定理
   - `[代数化简]` — 合并的机械变形，须点名做了什么
3. **中途检查点**：每 5–10 步暂停核对——量纲/单位一致、符号守恒、变换性质正确、边界条件未被破坏。
4. **分支**：出现分类讨论（如退化/非退化、有无套利）时，每支作为带标签的子推导，最后合并。

```markdown
## 推导

**第 1 步.** [起点表达式]
*依据*：[假设 / 定义]

**第 2 步.** [对上一步的操作结果]
*依据*：[具体理由]

...

**检查点（第 N 步后）.** 核对：
- 量纲：[核对]
- 符号/变换：[核对]

...

**第 M 步.** [最终表达式 = 目标结果]
*依据*：[最后一步操作]  ▢
```

**失败处理**：若某步不能由前一步推出，即为断点——补上中间步骤，或指出所需的额外假设。**严禁**用"可以证明""显然"跳过步骤，除非该结论已在第 2 步列为具名恒等式。

### 第 4 步：核对极限与特例

至少核对三项，并制表：

```markdown
## 极限情形核对
| 情形 | 条件 | 应有结果 | 代入所得 | 是否相符 |
|------|------|---------|---------|---------|
| [名称] | [参数极限] | [已知结果] | [代入] | 是/否 |
```

- **退化情形**：如波动率→0 应退化为无风险；相关系数→±1 应退化为两资产极值。
- **特例取值**：如 n=1、单期、两资产、均匀权重。
- **量纲/符号检查**：结果方向是否符合直觉与已知结论。
- **与相关结果一致**：是否满足一价定律、无套利界、求和恒等式。

**失败处理**：某项不符 → 回查是哪一步首次产出破坏该极限的表达式。常见病因：符号反了、漏了 1/2 因子、组合系数错、极限次序不对。

### 第 5 步：成稿（结果 + 符号表 + 假设汇总）

1. 引言段：点明动机、思路与主要结果。
2. 推导主体：把第 3 步整理为可读分组，配小标题（如"将目标式展开至二阶""代入约束"）。
3. **结果框**：最终结果单独高亮。
4. **符号表**：每个符号的含义、单位、首次出现位置。
5. **假设汇总**：区分基本假设与技术性假设（如正则性、收敛性）。

```markdown
## 最终结果

> **结论**：[精确陈述]

## 符号表
| 符号 | 含义 | 单位 | 首次出现 |
|------|------|------|---------|

## 假设
1. [基本假设]
2. [技术性假设]
```

## 四、输出形态

- 默认输出**可直接嵌入讲义 `examplebox` 的 LaTeX 片段**（中文叙述 + `\[...\]` 展示数学）。
- 若调用方要求 Markdown，则按 Markdown 输出。
- 推导较长（>50 步）时拆为若干引理，分推后汇总引用。

## 五、常见错误（务必自查）

- **隐藏假设**：默认函数可微/级数收敛/积分存在却不声明。
- **符号错误**：最常见。用逐步符号追踪与量纲检查交叉验证。
- **丢掉边界项**：分部积分/换序时边界项消失必须说明理由。
- **极限次序**：不同次序可能给不同结果，须显式声明并辩护。
- **循环论证**：用待证结论作中间步骤。对"看起来很熟"的公式尤其危险。
- **记号冲突**：同一字母表两意（如 r 既表收益率又表利率）。
- **滥用"代数化简"标签**：把需要解释的操作藏进"化简"里，等同于跳步。
