# exam-problems（例题精解）

把课件里可计算的题型整理成**成体系的例题集**。例题是应试价值最高的内容，**必做**；但**只做课件里已有的**。

## 一、例题来源（唯一）

1. **课件原题**：忠实转录，**不做简化、不跳步**，保留原始给定值。
2. **课件中老师课上的例题**（L2 双源场景）：若录音转写里有老师当堂带着做的题，也算课件例题，一并整理。
3. **不自行出题。** 不得自造变式、不得为凑数量造同法题目。

> **明确禁止**：自造题目、构造同法变式、为"方法覆盖完整"而补题。
> 课件的题就是讲义例题的全部来源。

## 二、扫描（三步）

### 2.1 抽文本层找题

对全部抽取文本，用关键词扫描：

```text
例、例题、例題、已知、求、计算、求解、证明、推导、给定、设、
解、答案、概率、期望、方差、收益、久期、波动率、权重、最优、
表格、矩阵、步骤、过程、输出、分类、预测
```

记录**题型**（而非具体数字）：**同一方法换不同输入 = 同一题型**。

```
题型：[短名]
出处：[文件, 第 N 页]
方法/公式：[名称]
原题数量：[N]
```

### 2.2 OCR 补扫图片题

大量例题**整张在图里**（截图、手写、嵌入表）。文本层会完全漏掉。必须把每页 PDF 渲染为 PNG 并 OCR：

```python
# 首选 PyMuPDF(fitz)；未安装时用下面这个 pypdfium2 版本（本机实测可用）
import pypdfium2 as pdfium, subprocess, os

def pdf_to_pngs(pdf_path, out_dir, scale=3):
    """scale=3 约合 216 dpi，足够 OCR 与裁图"""
    os.makedirs(out_dir, exist_ok=True)
    doc = pdfium.PdfDocument(pdf_path)
    paths = []
    for i in range(len(doc)):
        img = doc[i].render(scale=scale).to_pil()
        p = os.path.join(out_dir, f"page{i+1:03d}.png")
        img.save(p); paths.append(p)
    doc.close(); return paths

def ocr_image(img_path):
    return subprocess.run(["tesseract", img_path, "stdout"],
                          capture_output=True, text=True).stdout

def pptx_to_pdf(pptx_path, out_dir):
    subprocess.run(["soffice", "--headless", "--convert-to", "pdf",
                    "--outdir", out_dir], check=True)
```

整页渲染的最省事做法（poppler 随 TeX Live 提供）：

```bash
pdftoppm -r 200 -png "deck.pdf" figures/page    # → figures/page-01.png …
```

命中关键词的页面：**目视图** → 读懂整题 → 记全（给定值、问法、全部步骤、最终答案）→ 记下涉及哪几页。

> **跨页规则**：题目从第 N 页开始、延续到 N+1、N+2……必须**读完所有续页**再落笔。**只给设定不给解答的例题不合格。**

### 2.3 去重归型

- 不同数字 / 不同输入但**同一方法** → 同一题型。
- 同一方法用在**根本不同的语境**、解法流程不同 → 才算新题型。

产出清单：

```
题型清单：
[第 N 章] 题型 1：[名称] —— 课件原题 N 道
[第 N 章] 题型 2：[名称] —— 课件原题 N 道
```

## 三、覆盖要求

**课件有多少题，讲义就整理多少题**——全部收录，不遗漏、也不多加。

| 课件中该题型的情况 | 讲义中 |
|---|---|
| 有 N 道原题 | 全部 N 道，忠实转录 |
| 课件教了方法但**没给例题** | **不补题**。该方法的例题位置留白，由理论小节把方法讲清楚即可（见下）|
| 课件未教的方法 | 不出现在讲义里 |

**「课件教了方法却没配例题」的处理**：不自行出题。该方法的例题位置留白，由理论小节把方法讲清楚即可（含必要的推导与适用条件说明）。
不要为了"覆盖完整"而造题，也不要为此添加任何提示性文字（如"课件未给例题"）——留白本身即可。

## 四、LaTeX 格式（统一用 tcolorbox）

**颜色约定**（**优先用模板自带环境，不要自己现造盒子**）：
- 蓝框 `examplebox` = **课件原题**（本 skill 的唯一用框）

```latex
% 课件原题 —— 蓝框
\begin{examplebox}[Example]
\textbf{例题 N：描述性标题}

\textbf{已知}：[全部给定值/参数/设定]

\textbf{求}：[要算什么]

\textbf{解答}：
\begin{enumerate}
  \item \textbf{步骤 1 名称}：[本步算什么，用什么公式，中间结果]
        \[ \text{公式} = \text{结果} \]
  \item \textbf{步骤 2 名称}：[下一步计算，算式完整]
\end{enumerate}

\textbf{答案}：[最终数值或符号结果]

\textbf{解读}：[一句话说明结果的金融/数学含义]
\end{examplebox}
```

> 若所用模板中确实没有 `examplebox`，才退回原始 `tcolorbox` 写法：
> `colback=blue!5!white, colframe=blue!75!black`。
>
> **`variantbox`（绿框）不再使用**——它原为自造变式专用。模板中可能仍保留其定义（向后兼容），但本流程不产出该框内容。

**编号**：全篇连续编号「例题 1…N」，**不按章重置**。若第 1 章到例题 16，第 2 章从 17 起。

**放置**：每套例题必须紧跟在**讲解该方法的理论小节之后**。严禁把例题集中堆到章末或附录。

## 五、数值正确性（不可妥协）

1. 落笔前**逐步重算**（手算或程序核验）。**错例题比没有例题更糟。**
2. 算法走查类（DP 表、树、网格）**必须补全完整的表**，即便课件只给了部分步骤。
3. 检查中间结果衔接：第 2 步用了第 1 步的输出，要核对数值。
4. 若某步复杂到无法完全验算，在 `.tex` 中加 `% TODO: verify` 注释并**在框内注明存疑**。

## 六、完成前检查

- [ ] 课件里每一道可计算的题都已收录（不遗漏）
- [ ] **没有任何自造题、变式题**（全篇 `variantbox` 计数为 0）
- [ ] 每道例题都有：已知、求、编号步骤、答案、解读
- [ ] 跨页原题未被拆开——每个 tcolorbox 都是一个完整题目
- [ ] 全篇连续编号，无重置
- [ ] 例题全部用蓝框 `examplebox`
- [ ] 例题与其理论方法在同一小节
- [ ] 在 `.tex` 顶部以注释块存档题型清单：

```latex
% 题型清单：
% 第 1 章 — 题型：久期计算（课件原题 3 道）
% 第 1 章 — 题型：投资组合期望收益（课件原题 1 道）
% 第 1 章 — 题型：CAPM 参数求解（课件未给例题，留白）
```

- [ ] 无例题使用课件未教的方法
- [ ] 所有数值已验算

## 七、强制规则

- **例题必做**，但**只做课件里已有的**。任何有可算形式的方法，若课件给了例题就不得遗漏。
- **禁止自造题目**、禁止构造同法变式、禁止为凑数量补题。
- **课件没给例题的方法就不出题**——把方法讲清即可，不要补题。
- **不得出现跨页残题**。
- **数值正确性不容商量**；不确定就标 `% TODO: verify` 并注明。
- **严禁把例题堆到章末**，必须与理论同节。
- **全篇连续编号**。
